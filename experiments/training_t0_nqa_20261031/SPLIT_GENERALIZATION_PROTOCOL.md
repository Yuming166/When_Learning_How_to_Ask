# 世界级划分与训练外泛化

## Material Passport

T0 设计，未生成任何新世界、训练 seed 或评测 seed。以下表是 T1-KLD-v1 的候选冻结配置；执行前应连同实现和资源许可另作执行冻结。

## 数据隔离单位

使用全新的 development 根随机域和全局唯一世界索引；不得读取 Phase 3 确认 seed。Exact generator 的既有 split 仍为 `development`，训练/验证/独立开发角色由 evaluator-only 的域分离 key 和清单管理，不重新定义或修改 Benchmark generator。

先分配 role，再生成世界。一个世界的 theta、类型、参考样本、所有行为策略、采样前缀、增广排列、Teacher 标签及 Student rollout 必须同属一个 role。不同角色使用独立潜在响应流，不能把同一轨迹的不同状态随机拆分。标准化、缓存预填充、量化中心和所有模型选择只由 train/validation 角色允许的统计决定。

已完成 Phase2a–2e 的世界、旧 Qwen pilot 的 120 个世界、T0 的 8 个 profiling 世界、未来 Phase 3 世界均不参加本新协议的拟合或独立评测。T0 看过的 p/q 配置不是全球未见分布；“held out”只表示从此次训练角色的配置表中留出。

## 有界候选规模

提案为 128 个训练世界、32 个验证世界、64 个独立开发世界，合计 224 个新世界；当前实际生成 **0**。训练世界按确定的配置轮转表分配，禁止根据标签难易或后验误差再选世界。最多每世界八个保存前缀、约 1024 个训练标签；保留不完整标签分母。

训练基础网格：p∈{.70,.80,.90}，q∈{.50,.60,.65} 且 q<p；eta=.05；s=.80；partition∈{[1,1],[1,3],[4]}；alpha∈{0,1,3}；R∈{16,64}。完整笛卡尔积大于世界预算，因此先保留两个公共参考配置，再按 `sha256(version|canonical_condition)` 的固定次序选128个配置槽，不声称每个组合都有足够独立样本。角色清单在新根随机域生成前锁定。

64 个独立开发世界按八个预定层各 8 世界，不做事后改层：

|层|与训练表的关系|检验内容|
|---|---|---|
|ID|训练支持内新世界，仍完整隔离|最基本摊销与查询非劣性|
|Rate interpolation|p=.85,q=.55，其他为训练值|此次权重训练未见的组合插值，非历史全新率|
|Rate extrapolation|固定轮转 (.65,.50)、(.94,.80)|较弱通道/训练范围外可靠率；保留更多删失的可能|
|Grouping|d=4,partition=[2,2]|同 d 未见组大小配置|
|Fact count|d=3,partition=[1,2] 或 [3]|训练只见 d=2/4，检验真正未见 d|
|Calibration|alpha=2（插值）/6（外推），其余训练值|未见校准比例，非偷换为更多免费数据|
|Risk/budget|R=128/256、B 为原计划 cap|未见风险尺度与查询长度，不能把改变 R 当作只改变 cap|
|Joint shift|上述未见率、d=3、alpha=6、R=128 的固定组合|联合分布移动；不据结果挑较有利组合|

s 的跨值泛化和 d>4/G>2 均不是本有界主评测。可作为之后独立扩展；目前结构原型支持变长不等于教师或认证器支持该范围。具体两配置×四重复槽的完整元数据清单见 T1_CONDITION_ROSTER.json。弱通道外推层固定 R=16，风险外推层固定训练内率，避免把本来就不够的公共 cap 或同时更换多个因素误当作 Student 单项泛化失败；这些是执行前的设计选择，不基于 Student 效果。每层额外的组/事实置换仅作同一世界的等变检查，不能充当新的独立样本。

## 预算、读数与门槛精度

最大在线 cap 为 `max(2048,24R)`，R=256 时为6144。固定预算读数预定为 {64,128,256,512} 与 cap 的合法公共前缀；完成后携带终止答案/付费成本前推，不重复获取，也不把同一路径的多预算读数当独立世界。需要更早/更难预算以避免天花板时，应在执行冻结前确定，不能看本次测试后追加有利读数。

八世界/层只适合 bounded development。报告配对原始向量、分层均值与不确定性；若 5% 非劣性边界的区间太宽，应判 REVISE/INCONCLUSIVE，不自动增样、换 seed 或改 cap。它不是有充分功效的确认协议。任何以后扩大规模与 Phase 3 计划独立审批、独立冻结，不能混入本轮后提升证据身份。

## 泄漏审计

导出 Student 输入时必须从字段白名单重建，不能从含真值/评分的行删除几个键后直接序列化。训练与评测的 key、输入哈希、父轨迹清单需做交集检查；无身份 token、不跨角色 dedup 后重分配困难例、不以评测结果调整特征或解析器。评测标签由 evaluator-only 计算，并在学生进程退出后写入结果，不提供 score RPC。
