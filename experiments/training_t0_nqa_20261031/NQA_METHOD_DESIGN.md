# Neural Query Allocator：先学习分配，不同时替换估计器

## Material Passport

T0 方法设计；当前仅有未训练的 NumPy 接口原型 `t0/nqa_reference.py`。所有性能改善和学习能力仍待 T1 独立评估。

## 一、选择可摊销的映射

冻结 Fused-Original 的计算可以拆成

\[
\mathcal D_t \xrightarrow{\text{联合后验近似}}
(\hat p_t,\hat q_t,\hat z_t)
\xrightarrow{\text{KL 信息规划}}(x_t^*,K_t^*)
\xrightarrow{\text{展开/跟踪}} A_{t+1}.
\]

T1-KLD-v1 **只替换中间的规划映射**。联合后验、强制探索、更新时钟、累计目标跟踪和认证停止保持同版本。这样计算节省可归于规划摊销；不会将估计变化、时钟变慢、停止变松造成的差别解释为训练收益。后验的近似积分误差仍是冻结教师的限制，不因蒸馏而消失。

教师系数求解器实际依赖

\[
\xi=(\hat p,\hat q,\alpha=M/R,\eta,\{(k_g,s_g)\}_{g=1}^G,\varepsilon(t)).
\]

历史和后验中更多信息先保存在完整状态账本里；第一版规划头不需要读取任务文字、真实参数、答案标签、原始 ID 或全部历史。R 和 t 通过 alpha、数值容差进入这个映射。剩余预算 B-t 不改变该固定置信教师的优化目标，因此不作为第一版 KL 头的快捷特征。

## 二、组概率质量输出与无损展开

教师的 a_g,b_g 是每个事实的高/低格式查询系数，c_g 是组类型查询系数，

\[
K=\sum_g k_g(a_g+b_g)+\sum_g c_g.
\]

Student 输出每组的三类**总概率质量**

\[
M_g=(M_g^+,M_g^-,M_g^T),\qquad \sum_g(M_g^++M_g^-+M_g^T)=1,
\]

其教师标签为 `(k_g a_g/K, k_g b_g/K, c_g/K)`。对于 j 属于 S_g，展开为

\[
w_{j,\hat z_g}=M_g^+/k_g,\quad
w_{j,1-\hat z_g}=M_g^-/k_g,\quad
w_{T_g}=M_g^T.
\]

这样覆盖了冻结教师的全部组内均匀分配，输出维度为 3G，不随事实数直接增加。若 Student 与 Teacher 都以此展开，则组质量上的 forward KL 等于完整动作分布上的 forward KL：每个组内的 k_g 项相加，分母中的 k_g 正好约去。没有为了压缩而丢失此教师的任务内分配自由度。

此表示并不覆盖 Fused-Info 或一般有限预算最优策略的逐事实非均匀分配。需要这一自由度时，应新增独立的事实集合编码与监督目标，不能仍宣称在做同一个教师的纯蒸馏。

## 三、轻量模型

主候选是组等变的共享编码器：

\[
h_g=\phi([\log(1+k_g),s_g,\text{type-available}_g]),\quad
c=[u,\operatorname{mean}_g h_g,\operatorname{sum}_g h_g],\quad
\ell_g=\psi([h_g,c,\text{local}_g]).
\]

u 包含 `p_hat,q_hat,p_hat-q_hat,log1p(alpha),eta,log1p(d),log1p(G),log(epsilon)`。对所有合法 `(g,+/-/T)` logits 作一个共同 masked softmax。没有类型动作时严格置零对应质量，不通过“非常小的正数”伪造禁用动作。额外小头可输出 `log K_hat`，仅作代理信息诊断与可选回退检查，不用于停止。

参考宽度：phi 为 3→32→32；共享组头为 107→64→3；K 头为 72→32→1，合计 **10660 参数**。当前原型权重来自固定工程 fixture 随机初始化，没有拟合、checkpoint、策略效果或训练速度结果。

基于集合的共享编码与聚合是已有方法思想，见 [Deep Sets](https://arxiv.org/abs/1703.06114)；这里的组质量展开与既有 KL 教师接口结合才是具体设计，不声称 DeepSets 架构本身新颖。浮点聚合只声称测试精度下的等变性，不作机器逐位对称定理。

对照 MLP 使用同一 reduced planning state，G<=2 时补齐组槽，缺失槽有显式 mask。可用 16→64→64→7 的约 5703 参数头；最后七维为六个组质量 logits 和 logK。不能让 MLP 和 DeepSets 使用不同的合法信息后把差别归于架构。

## 四、对称性与非唯一解

共享组头提供组置换等变性；展开器提供组内事实置换等变性；高/低规范坐标经已有 z_hat 映射回实际 A/B。z 后验恰好为 1/2 时，冻结教师的 A 优先 tie rule 不一定满足格式交换等变性，须保留这个例外。

有限精度 LP 在非唯一最优解时可能给出顺序相关的不同标签。原始标签、组顺序和容差全部保存。排列增强应同步置换已有标签，不为每个置换挑一个“更好看的”教师解。对不可区分的等大小、等 s 组，等变 Student 可能无法复现某个非对称极点，但能表达对称的等价解；不能只因 L1 标签距离大就判坏。

比较时同时报告估计模型下的最小信息、达到单位信息的成本系数和原教师 gap。对同质组最优解取对称平均在理想凸可行集内保持可行和成本；数值实现仍需重新核对分离残差，不将此理想论证冒充浮点证书。

## 五、可靠性与有限预算

Student 只输出采样权重，不能 STOP、提交答案、访问真值或修改风险 R。即使预测错误，外部认证器仍使用所有真实观测决定停止；因此可以保留原模型/算术条件下的错误认证输出控制，但可能严重增加成本或造成预算弃答。

模仿固定置信 KL 分配不等于直接优化有限预算成功率。T1 首先问“能否更便宜地保留教师查询效率”。未来预算条件策略必须有另行冻结的目标和教师/学习信号；不能混入 Fused-Info 的贪心信息标签，再称为同一个最优 KL 目标。
