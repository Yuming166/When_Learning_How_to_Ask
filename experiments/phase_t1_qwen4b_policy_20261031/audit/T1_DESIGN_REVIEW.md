Review type: independent native same-family research-validity and leakage review. This is not a cross-family review or formal verification. Reviewer scope is read-only source/public evidence inspection and this audit file; no worlds, seeds, model calls, training, or scientific replays are executed by the reviewer.

## Current verdict: PASS for frozen data generation; scientific training remains gated

The user authorizes one isolated, bounded Qwen3.5-4B LoRA imitation-learning pilot on fresh QRelBench-Exact development worlds. The purpose is to test whether a learned query-allocation policy adds practical value relative to both the frozen statistical teacher and a small neural student. The authorization does not require a positive result, authorize RL/search, or alter any prior method, benchmark, or confirmation artifact.

At the first inspection, the new experiment directory contained only the dependency-install log and the verdict was CONDITIONAL. The final source-bound review below supersedes that preliminary status for data generation. Generated-data validity and scientific training/evaluation execution remain subject to the separate pre-training gate.

## Design assessment and required interpretation

1. **Unit of independence.** The proposed 1,536 states are 16 correlated readouts from each of 96 distinct worlds: 64 training worlds, eight validation worlds, and eight worlds in each of ID, held-out-parameter, and held-out-partition test strata. These are not 1,536 independent observations. Split membership must be assigned before trajectory generation and apply to the complete world and all of its streams, histories, labels, and readouts. All test worlds must be fresh relative to training, validation, old experiments, and reserved confirmation instances.
2. **Test-world reuse and settled choice.** The same 24 untouched test worlds could validly support both offline-state and closed-loop evaluation if neither result tunes a model, but this would be correlated evidence. The subsequently available protocol instead chooses 24 **additional** closed-loop worlds disjoint from the 96 state-data worlds: 120 worlds in total. Source and receipts must implement that settled choice. The three fixed-confidence worlds are reused from closed-loop evaluation and are not independent confirmation. Do not tune on offline test results before closed-loop evaluation.
3. **Generalization scope.** Training rate pairs are (.80,.55) and (.90,.65); (.85,.60) is an unseen interpolated pair relative to T1 training, not extrapolation or a condition never used in previous research. Partition [2,2] is an unseen sharing pattern relative to T1's [4]/[1,3], with the same d=4 and at most two groups. Eight worlds per stratum cannot establish broad parameter or task generalization.
4. **One horizon convention.** The settled public cap is 2,048 for data generation and all policies in evaluation. Budgets 256/512 are intermediate evaluator readouts, not policy-known deadlines. Therefore the learner is not being tested on optimizing a known 256/512 horizon. Remaining budget must use the same 2,048 convention in every state. Training readouts t=8+128k, k=0,...,15, end at 1,928; label computation must precede the observations that follow that state.
5. **Teacher and scheduler controls.** Keep the original native-cadence Aligned baseline separate from Aligned-Block128, the teacher matched to the learner's update cadence. Use the same legal action adapter, block accounting, forced square exploration, and tracking implementation for matched policies. Any difference involving the native baseline mixes allocation and update cadence. D-RRC and the type-aware D baseline remain heuristics; neither is an oracle or a learned-policy optimality certificate.
6. **Observable inputs only.** Known partition, per-query response counts, forced counts, type-report counts, calibration counts, public R, cap, and remaining allowance are legitimate. Hidden answers, actual p/q, hidden group types, world identifiers, split identifiers, seeds, evaluator correctness/reward, teacher allocations, or oracle/KL diagnostics must never enter policy prompts or MLP features. The teacher must compute its label from that same observable state, without a hidden-parameter shortcut. World identifiers may appear only in evaluator metadata excluded by an explicit input allow-list.
7. **Output contract and failure denominator.** Use ten integer percentage slots (eight task actions and two padded type actions). Missing groups have exactly zero type mass. Validate shape, type, finiteness, sign, and nonzero legal total before normalization. Invalid outputs fall back to a declared uniform distribution over legal actions and remain in all denominators; never substitute the teacher or discard failed outputs. Base and LoRA use identical prompts, deterministic decoding, response length, parser, masks, and fallback. Quantization loss between real-valued teacher targets and integer labels must be measurable and distinguished from student error.
8. **Training exposure.** Freeze one epoch over exactly 1,024 training states, rank 8, alpha 16, effective batch 8, and no hyperparameter/checkpoint search. With microbatch one and gradient accumulation eight this implies 128 optimizer steps, subject to explicit dataset-loader accounting. Validation is diagnostic only and cannot select a checkpoint. Verify the actual token lengths, completion-only loss mask, and absence of silent truncation or row filtering before training. Freeze the base weights and save only the adapter separately.
9. **Small-student comparison.** The MLP must receive only the same legal state information and use the same masks and scheduler. Freeze its architecture, fitting budget, checkpoint rule, and output adapter before held-out evaluation. Report training and inference compute for both students. If it sees exact normalized counts while Qwen sees rounded values, or vice versa, disclose that representation difference. Preserve any mismatch between the teacher's estimator inputs and the larger legal feature set rather than attributing imitation gains to information the teacher does not use.
10. **Diagnostic scope.** The additional R=16 fixed-confidence diagnostic lies outside training R in {64,256}. Freeze its three selected existing test worlds before outcomes, retain all censored/error paths, and keep it separate from fixed-budget accuracy. The finite gate can certify a stopping decision under its mathematical/model contract for an arbitrary predictable sampler; it does not establish a learned policy's eventual stopping, finite expected cost, asymptotic optimality, or reliable web-language behavior. A forced-budget guess is not a certified stop.
11. **Accounting and inference.** Paired comparisons use the same world and keyed observation streams without leaking latent values. Show all attempted worlds, states, outputs, invalid fallbacks, censored paths, and failures. Report world-level paired uncertainty or raw paired vectors, not state-level independence. Costs must separate online acquisition, charged offline calibration, policy computation, decoder/gate computation, total wall time, teacher-data generation, and training. Inference latency is part of the practical comparison, not an optional afterthought.
12. **Bounded execution and preservation.** The protocol fixes five offline positions per each of 24 state-test worlds, hence 120 states per model and at most 528 planned Qwen policy inferences (240 offline +192 main +96 diagnostic), within a shared ceiling of 600 including technical inference checks. This supersedes the initial 128-state/544-call proposal. Environment smoke and training work must be separately counted; no performance-based reruns or replacements. Technical failures need durable receipts. Freeze code/configuration and old-artifact commitments before scientific generation, and recheck preservation afterward. No old confirmation data become new confirmation evidence.

## Source-bound review and final gate

### FINAL PRE-GENERATION VERDICT: PASS

The final `core.py` and `data.py` implement the announced isolation and legal-state design. Exact top-level and nested allow-lists reject hidden additions. Both textual prompts and the 69-dimensional MLP representation derive solely from validated state. The teacher is the literal frozen Aligned update, with a reference adapter that exposes only calibration lengths and raises if bit iteration is attempted. The teacher's derived sign/type estimates are retained in target diagnostics, never in the student input. The unquantized target and integer percentage label are both retained.

World plans contain 96 state-data worlds plus 24 disjoint evaluation worlds, using a new T1 namespace, separate split keys and distinct index ranges. Training covers the 16-condition factorial four times. Validation and ID state-test sets are complementary eight-cell parity fractions with balanced margins; they are not full factorials. Data generation emits all 16 pre-action readouts, installs their targets before subsequent actions, and stops each collection at t=1,928. The scheduler now rejects skipped update boundaries and actions beyond its public cap. The output parser rejects malformed/noninteger/wrong-sum/padded-mass outputs and uses only uniform legal fallback.

Generation refuses a missing or changed source/dependency freeze and refuses an existing output directory. It writes an initial manifest and the current attempted world before collection. Completed and failed worlds retain public consumed-action/calibration totals; partial failed-world data are sealed with file mode 0600 under a 0700 directory. No invalid world is silently replaced. Historical imports disable bytecode writes in the original tree. This is source and interface isolation, not a claim of operating-system separation between the trusted evaluator and policy code.

The reviewer independently ran the final **11 deterministic core/data contract tests: 11/11 PASS in 0.464 seconds**. These use handwritten observations or mocked environments, not scientific worlds or private seeds. They cover forbidden-field invariance, literal teacher alignment, calibration-value non-use by the teacher, invalid-output fallback without teacher access, overflow rejection, square exploration/tracking and block boundaries, complete-world split plans, all 16 pre-action readouts, frozen-dependency tamper rejection, and failed-world cost retention/permissions. The reviewer performed no model/GPU call or training.

Environment evidence records the actual local Qwen3.5 class, frozen base weights and text-only LoRA adapters. The first 70-token smoke was insufficient as a length-dependent memory check; the retained additional **1,024-token** forward/backward smoke passed with zero optimizer updates, 16,232,448 trainable FP32 adapter parameters on the BF16 base, peak allocated 12,415,349,760 bytes and peak reserved 13,274,972,160 bytes. Both technical smoke receipts remain available. Their zero generation count does not mean no forward/backward computation occurred. GPU allocation checks the selected device before use and serializes this task without touching the existing service.

The final protocol fixes 120 offline test states per model and 24 additional closed-loop worlds. The three diagnostic worlds are the first planned world in each stratum; all three happen to have **M=0**, so changing R64 to R16 retains zero calibration. The general evaluator retains M rather than redrawing it, but alpha=4 is not exercised by these three selected paths. The diagnostic therefore does not cover all calibration or condition cells. The public evaluation-plan commitment precedes the fresh seed.

The data are teacher-policy histories. Offline imitation on those histories is not a closed-loop guarantee under the student's changed state distribution. The independent closed-loop test, common block teacher, native-cadence reference and lightweight student are necessary controls. Fixed-budget methods spend the same online budgets by construction; accuracy and computation at those budgets, rather than a main-arm online-query saving, are the direct endpoints. Any query-saving statement from the three stopping diagnostics remains descriptive.
