# T1 — isolated Qwen4B query-policy training pilot

This is a development-only branch, `training/qwen4b_policy_t1`, separate from the original method and benchmark worktrees. The user authorized one bounded LoRA pilot and a lightweight control, with no RL or search. Start with TRAINING_PROTOCOL.md; required results are TRAINING_REPORT.md, QUERY_POLICY_EVALUATION.md, COMPUTATIONAL_COST.md, FINAL_DECISION.md and DATA_LEAKAGE_AUDIT.md.

The read-only original experiments are under `/home/gaoym/When_Learning_How_to_Ask/experiments`. Their exact source hashes are recorded in generation_freeze.json and training_freeze.json. They are local experiment dependencies, not silently imported from an unrelated Git revision. Historical receipts are independently preserved. The pretrained checkpoint is read-only, and `.deps` contains only isolated PEFT/Accelerate additions. Full runtime and checkpoint hashes are in audit/ENVIRONMENT.json.

Use the recorded Python `/storage/gaoym/wcl_v100_venv/bin/python` for model, data, training and evaluation stages. Before import, set PYTHONPATH to this experiment's `.deps`, PYTHONDONTWRITEBYTECODE=1 and OPENBLAS_NUM_THREADS=OMP_NUM_THREADS=MKL_NUM_THREADS=1. For GPU commands set CUDA_VISIBLE_DEVICES=3 and CUBLAS_WORKSPACE_CONFIG=:4096:8; the launcher refuses an occupied card. No inference service is modified. GPU indices and availability must be re-audited on another host.

The final JSON-only analysis/plotting stage uses the host's separate default `python` with NumPy and Matplotlib: `python -m t1.analyze`, with the same thread and bytecode limits. That interpreter does not load Torch or a model; the training interpreter lacks Matplotlib. Analysis versions and timing are retained in `artifacts/analysis/execution.json`. Reproduction needs both recorded environments, or an independently prepared environment containing their required packages; do not install plotting packages into the existing training/service environment merely to run the figures.

The actual one-time sequence is: deterministic tests; short and1024-token zero-update smoke (`python -m t1.qwen`, then `--long`); pre-generation audit; generation freeze; fresh evaluator-only T1 seed and `t1.data.generate_dataset`; `python -m t1.token_audit`; final data/source audit and training freeze; `python -m t1.run_mlp`; `python -m t1.train`; analysis-source freeze before test outcomes; `python -m t1.run_evaluation`; `python -m t1.analyze`; final audit and receipt. Logs preserve actual process outcomes. Training is one pass over1024 states/128 updates; no validation/test checkpoint selection.

No existing receipt, seed or run directory may be overwritten. For reproduction, create an isolated copy, retain exact source/config, original dependency hashes and private seed, and remove only the generated files in that copy before replaying the sequence. `generate_dataset(config, fresh_output, saved_development_seed, generation_freeze_path)` refuses pre-existing output directories. A different seed is a new experiment, not exact reproduction. Generation and training freezes are separate because the data audit requires generated rows. Analysis code is excluded from training-source freeze and committed separately before held-out model evaluation; it cannot change policy, fit, inputs or split membership.

Canonical student inputs are in each row's `messages` and `state` fields only. Teacher estimates/weights are supervised labels/evaluation metadata and never part of a model prompt or MLP feature vector. World identities live in manifest/analysis metadata, not prompts. Files under any `private/` directory contain evaluator provenance and must not be passed to learners or staged for release. Adapters are separately saved without merged base weights.

The public action limit2048 is shared by training/evaluation. Budget256/512 results are intermediate readouts, not predictions optimized for a known512 deadline. Original native-cadence Aligned and matched block128 teacher are separate controls. Fixed-budget decoded guesses are not certified outputs. Only the small R16 diagnostic can emit an interval-certified stop; cap abstention remains in its denominator. The three diagnostic worlds are existing evaluation worlds, not independent confirmation.

Inference allowance600 counts autoregressive policy-generation requests across base+LoRA. Training/validation forward passes, two zero-update backward smokes, CPU simulator actions, and external API calls are distinct quantities. All latency includes input construction and generation in the evaluator callback; cold loading and data generation/training are reported separately. Full fixed-budget paths, malformed outputs and uniform-legal fallbacks are retained. Final receipt binds the public evidence, private-provenance commitments and adapter hashes; it does not establish scientific effectiveness by itself.

`audit/PARSER_SENSITIVITY.md` is a post-hoc analysis of saved offline outputs that relaxes only the percentage-sum constraint. It makes no new model calls or worlds and does not modify the strict primary parser, closed-loop trajectories or frozen analysis. It cannot establish the closed-loop effect of a different parser. `audit/PRESERVATION.json` records a read-only rehash of 421 historical bound files, the three T1 source freezes and 14 checkpoint files.
