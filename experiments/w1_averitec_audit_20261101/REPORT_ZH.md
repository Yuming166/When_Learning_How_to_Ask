# W1：12 条 AVeriTeC 真实网页事实审计

**结论：W1 已完成；REVISE，当前证据不支持进入 W3。** 12 条冻结案例中，2 条可交给 W2 人工语义审阅，10 条隔离；没有替换失败样本。另有 1 条仅来自网页元数据的错误线索，不计入正文候选。没有建立可直接用于测量的“错误来源正文”，也没有建立三份独立可比较来源的案例。这里的 NO-GO 仅针对本轮适配结果及后续模型试验，不是证明 AVeriTeC 或 Web 分层模型不可行。

本轮取得了来源依赖、命题范围漂移、证据链接错配及页面内部冲突的实例。这支持继续研究 Web 信息获取中的来源与证据单位问题，但**尚不支持自然共享可靠性、查询形式迁移、重复读取错误率或方法优越性**。Y 未采集，人工签核为 0，Qwen/其他实验模型服务调用为 0。AI 辅助审阅及复核不算人工签核，也不算跨模型验证。

## 4. 对 Web 建模有用的发现

**命题与证据绑定必须先于可靠性估计。** W1-05 的 QA 文本与核查文章结论相符，但所给 WPR URL 是另一年度统计。W1-07 的 QA 引用诊所段落属于 Melbourne，而数据集声明写 NSW；官方 NSW 公告虽然描述患者见过 GP，仍未证明是同一诊所接待多人。不能把这些错配算成同一事实的自然来源冲突。[旅游核查](https://www.politifact.com/factchecks/2020/jun/12/sara-meaney/yes-state-has-seen-drop-more-billion-tourism-dolla/)、[WPR 指定文章](https://www.wpr.org/wisconsins-tourism-industry-sees-30-percent-spending-decline-2020-due-covid-19)、[ABC 指定文章](https://www.abc.net.au/news/2020-01-25/first-confirmed-coronavirus-case-australian-as-china-toll-rises/11900428)、[NSW 原公告](https://www.health.nsw.gov.au/news/Pages/20200125_03.aspx)

**多个 URL 不等于多份独立证据。** 同一文章的归档、当前地址和重复 QA 引用不能增加独立样本数。W1-05 的报道与核查追溯到同一研究系列；W1-11 的 SI 明确归因于 Radar，并转述同一双方声明。这里记录的是可观察的归因关系，未估计统计相关系数，也没有识别独立证据的真实成本。[旅游研究归因](https://www.politifact.com/factchecks/2020/jun/12/sara-meaney/yes-state-has-seen-drop-more-billion-tourism-dolla/)、[SI 指定文章](https://www.si.com/nba/2018/08/02/blake-griffin-child-support-payments-detroit-pistons-los-angeles-court)

**一个页面可能不是一个二元报告。** 有的页面并存断言与否认；有的只是转录发言；有的需要作者署名与戏仿说明才能确定立场。SI 在独立 AI 复核中由暂定 V=0 降为 null，原因是其更新只表明报道了否认，未独立判定实际金额。不能为取得正向样本而放宽此规则。[SI 的更新说明](https://www.si.com/nba/2018/08/02/blake-griffin-child-support-payments-detroit-pistons-los-angeles-court)

对于后续理论，可把来源观测定义为“命题、版本、发言主体明确的证据单元”，并先允许不可判定/混合状态；二元 θ→V→Y 模型只覆盖经筛查的子域。来源依赖的定理仍须建立在明确的概率假设上，本审计只提供动机与边界，不是定理验证。

## 5. 能写与不能写

可写：固定规则抽取的 12 个开发案例揭示了适配损耗及来源依赖；保留了全部失败；成熟 fact-check 数据不能未经逐页验证就转换成独立二元网页报告。两条候选可以作为后续人工审阅材料。

不可写：发现了可重复的自然共享可靠性结构；证明错误网页被模型正确读取；测得 A/B format gap、persistent error、迁移或校准效果；验证了原方法在真实 Web 上的优势。三层变量四种错误组合当前全部缺少 Y，不能填写读取准确率或“错误抵消”统计。

**本轮停止点：**交付 W1，不扩样，不自动运行 W2/W3，不再下载新的补充来源。若未来继续，先由人审阅 P021、P028 两个候选及 P014 元数据线索，并另行决定是否改变证据单元定义。现有数据不满足启动 Qwen 读取实验的条件；Method、CRAG、M3 和训练工作未被本任务重跑或修改。
