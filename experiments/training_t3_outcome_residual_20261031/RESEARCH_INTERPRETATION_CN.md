# T3 研究解读（结果后补充）

本轮判断：**训练已经真实完成，但不建议把这套策略加入 WWW 主方法（本轮 NO-GO）。** 这不是“强化学习无效”的普遍结论，也不否定更精确的收益监督或其他训练分布可能有用。

本轮训练了9个轻量模型：任务分配、类型购买、联合决策各3个种子，每个模型1,857个参数。完成4,680次优化更新，保留36个候选检查点。48个独立训练世界产生192个状态、372个联合残差状态—动作样本；这些样本不能当作372个独立世界。24个开发世界选权重，随后只打开一次192个独立测试世界。测试不选模型。

| B32 策略 | 完整恢复 | 主要观察 |
| --- | --- | --- |
| 冻结 WorstFact-MI | 151/192 | 主参照 |
| 冻结 Fresh-IG-Lite | 155/192 | 高于选定联合模型1个世界 |
| 固定规则切换 | 157/192 | 无需训练 |
| 固定类型购买 + 事实级 IG | 157/192 | DEV选定的最强冻结参照 |
| 学习任务分配 | 151/192 | 与主参照同总数，不代表逐世界结果相同 |
| 学习类型购买 | 148/192 | DEV上的优势未延续到测试 |
| DEV选出的联合模型 | 154/192 | 相对WorstFact +1.56pp，配对95%区间[-2.08,5.21]pp |

三个联合种子的测试恢复数为151、154、151；不重选测试赢家。选定模型在未见校准比例层，相对固定类型对照少恢复3/48个世界（-6.25pp），未通过事前的工程退化门槛；这一小样本差异的区间跨0，不能反过来声称已证明总体有害。

估计误差也未建立改善：联合 Brier 相对WorstFact差值-0.01294，配对95%区间[-0.04527,0.02043]；NLL差值-0.03237，区间[-0.09558,0.03203]。同一个联合估计器收到不同查询数据，不能将描述性分数下降写成“训练改进了估计器的统计保证”。错误计数中的 theta_errors 来自共同后验的逐事实边际MAP；完整恢复和提交答案使用共同的联合向量MAP，两者必须区分。

计算瓶颈也更清楚：九次参数拟合合计约1.87秒CPU，训练/DEV标签函数合计约130.60秒CPU；完整科学运行到测试结束累计约1,018.31秒CPU，四路并行各阶段墙钟合计约323.24秒（不含开发代码与撰写报告的时间）。B32下，选定联合模型192世界的运行CPU为36.80秒，WorstFact为14.26秒，约2.58倍。联合模型的网络前向只用了0.218秒；其主要开销仍在联合后验、KL候选规划和特征/候选计算。小网络前向很快不等于整套策略更快。

所有配对策略均用满相同B，任务和类型查询均单价1，离线观察均计2M。因此没有证明在线查询成本或总获取成本下降。训练数据的获取和标签计算也不是免费资源。

认证方面，4,488条计划轨迹均完成，无基础设施失败、无缺失轨迹；终局认证通过0条，正常拒绝4,488条。已认证输出的错误率分母为0，不能把“错误认证0次”写成一个经验正确率保证。预算末猜测仍只是固定预算准确率，既非delta-correctness，也非一般数值认证或渐近最优结论。

## 标签信号诊断：事后描述，不参与选模

仅利用已经保存的模拟，未追加任何rollout或训练。训练标签两半模拟的残差相关系数约0.085，DEV约0.117；越过固定0.02偏离阈值的两半一致率约66.9%与65.7%。单个残差均值的平均Monte Carlo标准误约0.0268与0.0282，已经大于0.02动作阈值。这提示收益监督较弱，是本轮未建立决策优势的一种可能解释；它不能单独证明失败原因，也不能推断增加模拟必然成功。完整数值见 LABEL_NOISE_DIAGNOSTIC.json，明确标记 POSTHOC。

只有一次冻结、一次有界训练Pilot，没有按测试结果改阈值、换训练分布、增加模拟、追加训练轮数或启动PPO。弱探索门槛通过，代表允许尝试，不代表已经证明可学习性。开发集上的部分收益预测MSE甚至不如始终预测零增益。

保留负结果，停止本轮。本文可保留为“有限预算训练未带来额外价值”的开发证据；目前不应作为新增的有效方法贡献。任何下一轮应另行授权、另定协议，而非自动扩大训练直到获得正结果。

补充统计限制：某分层中所有配对差异为0时，经验配对bootstrap可能退化成[0,0]；这不证明总体等价。次要预算各48个世界与B32世界重叠，不是额外独立样本。任何结果仅支持这套QRelBench-Exact数值模型与固定网格，不支持真实语言/Web迁移。
