# W2 human review packets — PENDING

Two packets prepare the original W1 candidates; they do not attest that any
human has read or approved the evidence. A person must read the frozen source
context and complete the form. An AI agent must not fill the human identity,
reading attestation, judgement or signature on that person's behalf.

1. Read the original proposition and source context in the case packet.
2. Inspect the named frozen W1 representation. Follow the original URL only as
   optional context: a newer live page is a different representation.
3. Record the speaker, exact applicable scope, whether the author adopts the
   full proposition, and the limits of the reference truth. Preserve ambiguity
   and reject a case when necessary.
4. Fill the corresponding JSON form with an actual human identity/date and
   evidence/version confirmation. Leave unsupported decisions pending. Do not
   interpret an empty form as agreement.
5. Only then compare the person's judgement with the AI proposal outside this
   packet. Disagreement needs adjudication, not majority-by-agent counting.

There is no automatic approval/import script and no model pilot.
