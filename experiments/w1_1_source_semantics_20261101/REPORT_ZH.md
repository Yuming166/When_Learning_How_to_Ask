# W1.1：Web 来源语义与来源关系修复

**W1.1 表示审计已完成，可以保留为 Web 理论的开发材料；目前不进入模型读取试验。** 原 W1 的 12 条声明、50 个真实 URL、2 条待人审候选、10 条隔离结论全部保留。新版本没有通过放宽标签增加二元样本。两个人工审阅包已准备，真正人工签核仍为 PENDING。

本轮仅使用 W1 已冻结材料，新增网页请求、声明、模型调用、Y 观测、训练和方法实验均为 0。W1 的 78 个封存文件及其 manifest 在开始和收尾时均校验；本目录是事后开发性表示修订，不是独立确认集。

## 1. 修复了什么

每条原始声明增加实体、关系、数值、事件时间、地理范围、单位与限定条件。缺失的谓词、时间区间或原始主体继续标为不确定，没有把目标偷偷换成易判断的子命题。原标签保留为 θ 的参考结论，而非独立审定的客观真值。

每页增加五种语义标签，并单独记录缺失状态。每条可定位的相关陈述保留发言者、出版方是否采纳、命题极性、精确短片段和位置。正文、HTML 元数据、标题壳及未取得的历史快照分开；47 条短片段均已在冻结材料中核对。完整记录见 [CASEBOOK.md](CASEBOOK.md)、[页面表](page_semantics.csv) 和 [陈述索引](statement_index.csv)。

| 完整目标的页面语义 | URL 数 | 解释 |
|---|---:|---|
| ASSERT_SUPPORT | 3 | 全部是参考核查文章，仍是 evaluator-only |
| ASSERT_REFUTE | 5 | 4 篇参考文章，1 篇原始出版物的作者归属说明 |
| ATTRIBUTED_ONLY | 2 | WISN 完整同比说法、Washington Post 辩论转录 |
| MIXED | 3 | Radar 两路径与 SI；实际仅两个文档谱系，不是三份独立证据 |
| NOT_ADDRESSED | 11 | 已读内容未回答完整目标；包含主页/表单及不同范围子命题 |
| UNOBSERVED | 26 | 未取得可标注正文；不能当成“不支持”或错误 |
| **合计** | **50** | 另有 4 条声明×Metadata 占位记录，不算网页 |

24 个 URL 有正文/通用界面的语义摘要；另有 1 个元数据表示和 1 个标题壳表示，共 26 个观察表示。这里的表示可来自浏览器较早缓存，不能当成审计日实时内容或原事件时快照。8 个直接支持/反驳页面中，7 个是参考文章；唯一非参考、完整直接断言候选是 P028。独立人审后批准的二元子集仍为 **0**。

## 2. 哪些隔离来自表示限制，哪些仍是真实不足

下面两类原因可以同时成立，不把它们人为分成互斥标签。表示更完整，不代表缺失的真值、原文或版本证据已经补齐。

| 案例 | 可以保留的语义信息 | 仍阻止二元实验的原因 |
|---|---|---|
| W1-01 | 非 URL 占位与访问失败 | 参考及普通来源原文缺失 |
| W1-02 | 人口、法官数量与运算是不同子命题 | 原文不可读，年份与源数值未核验 |
| W1-03 | 参考文章明确反驳绝对过滤命题 | 原帖及普通证据不可读，参考文章不能充当独立错误源 |
| W1-04 | 帖子元数据断言、停测子命题、核查反驳可分开 | 原帖正文与历史版本未得；暂停检测不等于封闭实验室 |
| W1-05 | 标题部分采纳与完整采访说法分开 | 同比基准来自被引发言，独立数据未重算，人审未完成 |
| W1-06 | 实际作者、戏仿说明、虚构叙述三层声音 | 人审未完成，说明何时加入未知；不是自然错误来源 |
| W1-07 | 地点、具体诊所与不同患者分开 | 原目标单诊所/多人歧义、核查对象漂移，不能改题救回 |
| W1-08 | 发言人观点与出版社立场分开 | 原始民调未审，QA 是主页，参考结论有特定口径 |
| W1-09 | first 与 only、授勋时间与发文时间分开 | 原文不可读，第一手授勋记录未审 |
| W1-10 | 问句标题、搜索表单不当作断言 | 原始目标缺归属谓词，参考正文缺失 |
| W1-11 | 正向报道、否认与更新说明分别归属 | 金额保密、原始裁定和修订前版本未得；否认不是独立核验 |
| W1-12 | 支出定义、实际/计划支出、不同时间总量分开 | 十年区间未定，目标金额未重现，参考页缺失 |

W1-04、07、08、11 等隔离材料因此仍有合法的 Web 语义用途；没有哪一条原隔离案例仅靠改 schema 就成为已核验二元事实样本。[逐案原因记录](quarantine_diagnosis.json)

## 3. 两个关键口径

**WISN P021：**W1 的历史结论仍是待人审候选。W1.1 对完整同比目标采用更保守的 ATTRIBUTED_ONLY，另存标题的部分采纳。这里改变的是事后开发的表示，不是重新宣告 W1 已通过或追溯改写 W1。是否能把标题与采访合成完整的出版方承诺，应由人工明确裁定。

**SI 与 Radar：**三个 URL 都保留相反说法，故为 MIXED。Radar 自己采纳金额断言的部分，与其引述的否认，是不同陈述；SI 对金额及否认的转述也分开。明确可归属的陈述并不自动等于独立正确或错误的事实。对社交帖同样区分发帖人与平台，平台未采纳不消除用户自己的断言；P014 受限于仅有元数据。

## 4. 来源图与未知依赖

图包含 50 个 URL 节点、40 个“指定文档身份”组、26 个观察表示、47 个陈述和 7 个具名材料谱系。**40 和 7 都不是独立根节点数量。** 归档地址可标记它指向哪篇原文，不能证明不同时点内容相同；引用也不能把两个网页的所有信息合并。[来源图与示意](PROVENANCE_GRAPH.md)

金额报道与联合否认是两个可追踪的共享材料链；同一 SI 页面属于两条链。研究系列、公共卫生机构或民调只是已知公共输入时，保留其版本、具体报告或其他证据未知。未取得原帖正文的转载关系继续标为二手报道，未验证实际复制。

全部 104 个同一声明内的 URL 对均有记录：11 对同指定文档、8 对已知共享材料/具名上游、3 对明确引用、5 对未解决关系或目标错配、77 对 UNKNOWN_DEPENDENCE。所有对的统计独立性均为 NOT_ESTABLISHED，不能按组件数计算独立证据成本。[依赖明细](dependency_pairs.csv)

## 5. 自然错误与修正记录可行性

只审查了冻结语料中的四类线索，没有新抓取或扩大数据：SI 更新说明、Radar 金额报道与否认、McSweeney 戏仿说明、Facebook 元数据与核查文章。结果均未建立“原始错误正文 + 可比版本 + 独立修正核验”的完整链。[线索审计](natural_error_feasibility.json)

SI 说明文章补入了否认，不能据此重建修订前正文或断言实际金额已被公开核定为假。HTML 自报发布/修改时间也不说明具体哪句话何时修改。McSweeney 明示戏仿不是原作者真实书信，但没有证据表明该出版社曾将其当真实书信发表。故独立核验自然来源错误为 **0**；这不等于自然 Web 没有错误，也不评价其他未审查的纠错数据库。

## 6. 人工审阅与受控备选

原两个候选已各有一份无签名的证据包和空白表单。表单需要真正的人阅读冻结原文并填写归属、时间范围、参考支持及决定；AI 没有代签，当前状态是 PENDING。[人工审阅入口](human_review/README.md)

另提供一份 **design-only** 受控来源编辑方案：先核验种子命题，再为单一断言建立可审计编辑账本；分别比较重读同源、不同页面复制同一报告、构造独立新报告。编辑材料必须标 simulated / Web-derived counterfactual，不能作为自然错误证据。本轮没有生成编辑页、选择获胜参数或运行实验。[设计方案](CONTROLLED_CORRUPTION_PROPOSAL.md)

## 7. 对理论的直接帮助与停止决定

建议把候选生成结构写成“事实 → 上游报告集合 → 版本化、带归属的网页内容 → 模型读取”。多父来源、引用、戏仿和冲突属于网页内容层，不应提前压成一个二元 V。数据参考标签也应与未知客观真值区分。来源独立性、观测核和成本定义仍需另作数学假设；不能直接继承现有信息复杂度与停止定理。[理论交接说明](THEORY_HANDOFF.md)

| 后续用途 | 本轮决定 |
|---|---|
| 保留多状态自然 Web 审计作理论动机 | **GO，开发性证据** |
| 两条原候选的真实人工签核 | **PENDING，证据包已备齐** |
| 建立自然错误来源实验子集 | **NO-GO，本固定语料未达到条件** |
| 立即开始有界模型读取试验 | **NO-GO，人审与读取目标尚未冻结** |
| 受控来源编辑 | **仅设计，尚未构造或执行** |

后续若人审通过，也只能讨论小型归属读取机制演示；现有数据没有共享可靠性分组或 format gap 观测，仍不足以支撑方法排名或根节点获取成本的实证结论。
