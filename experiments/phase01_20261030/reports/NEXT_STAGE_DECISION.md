# Phase 1 review and conditional next-stage plan

This is a conditional implementation plan, not authorization for more model calls. The current run stops at the development report. No Phase 2 optimization or confirmation data collection occurs automatically.

## Read the evidence in this order

1. Coverage and technical validity: all planned counts, invalids, model identity, private/public evidence separation. An incomplete run is not a negative scientific result.
2. Replication and transfer: independent-half group gaps and different-preference/different-wording transfer. A favorable average format gap alone does not support group learning.
3. Trivial recoverability and headroom: fixed/RR, direct/private self report, public metadata, and the audit-only oracle references. The hindsight maximum is upward biased; do not call its gap recoverable information.
4. Label-free learnability: compare the simple agreement probe with the labelled-calibration audit. Strong labelled transfer with weak agreement motivates a learning question; it does not show that a permitted algorithm already works.
5. Channel boundaries: persistent wrong answers, below-chance cells and heterogeneous rates. These can invalidate the theorem model even when one format has higher aggregate accuracy.

## Conditional dispositions

| Observation | Scientific reading | Next authorized decision to prepare |
|---|---|---|
| No replicated gap or no between-preference transfer | Current scenario does not establish shared latent query reliability | Keep the negative result; propose a new independently seeded, evidence-symmetric task before requesting another bounded discovery run |
| Direct or public metadata reaches the meaningful reference ceiling | Little demonstrated need for online group learning | Use the simple baseline or choose a substantively justified alternative environment; do not remove visible information just to handicap the baseline |
| Labelled transfer exists but agreement fails | Structure may exist; learning it without labels remains unresolved | Write a Bayesian identifiability/finite-sample analysis and examine persistent-error mechanisms offline; do not give the learner audit labels |
| All frozen discovery gates pass | Development evidence supports proceeding to method design | Freeze a Phase 2 comparison protocol and request a separate execution decision |

## Phase 2 method specification to write only after review

Use posterior uncertainty over preference signs, group format identities and reliability parameters. Choose actions using expected decision-relevant information per query, with forced exploration and explicit costs for type questions. The theory supplies an allocation principle, not permission to treat heterogeneous Qwen observations as an exact common-channel model. Do not silently replace unknown p,q with true empirical labels, or presume that ordinary past answers are labelled high/low reference streams.

Give fixed-format, RR, direct-type and adaptive policies the same answer estimator, observation interface, total online budget, offline calibration allowance and failure rules. Count type questions and calibration acquisition. Separate the effect of query allocation from a stronger inference engine. The optional direct report does not have a known s_g merely because the simulator returned a format digit. Known-group size four with two groups does not meet the alpha=0 full-sharing zero-premium corollary.

Do not optimize or report final test performance on these 24 development profiles. After task, templates, analysis, priors, tie rules, budget and stopping rule are frozen, generate a new confirmation split from disjoint seeds. Any 35B replication must preserve payload identity/settings and be separately authorized. Report model-specific exceptions and retain every failure.
