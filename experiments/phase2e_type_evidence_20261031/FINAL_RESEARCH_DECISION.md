## 收益来自哪里

原分配器内单独换融合估计器，在 [1,3],R=256 两个 alpha 下的成本/R 分别从 11.546875→7.765625、8.53125→7.109375。再换新分配器只进一步到 7.46875、6.96875。第二步增益为 0.296875 [0.09375,0.546875] 和 0.140625 [-0.140625,0.40625]；后者区间跨零。这些是 n=4、未作多重比较校正的描述性区间。

同估计器 D-RRC-Type 是必要对照：Fused-Info 在全部 8 个单元的平均成本都更低，但这不等于总体支配。一个小 R 单元的区间跨零；运行时间显著更高，有限配置也不能代表新来源或新可靠率。当前没有为获胜而筛实例或删除不利路径。

额外分配收益也出现在禁用类型动作的对照里。因而“新方法更好”不能全部解释为更聪明地购买类型报告。对全部固定世界的资源汇总，Fused-Original→Fused-Info 少 1104 个在线动作，其中任务少 923、类型少 181；禁用类型时也少 1168 个任务动作。这些混合配置总和只作资源与机制描述，不替代逐单元成对比较。

购买时间方面，32 世界按 min(T,t) 计费，Fused-Original 与 Fused-Info 在 t=64 的平均类型数为 4.15625/3.0625，在 t=256 为 21.09375/19.65625；总类型数为 3316/3135。新规则确实不同地购买类型，但单独的购买时机因果收益尚未识别。[1,3],alpha=0,R=16 中新方法反而从禁用类型的 17.75R 增至允许类型的 19.25R，必须保留这一负结果。

固定前缀的去类型似然诊断也显示：在 64 次观测，完整融合答案 Brier 为 0.00650，去类型似然约 0.00464；完整融合类型 Brier 0.04847，去类型似然约 0.05064。额外类型证据并非在每个有限固定样本指标上都改善。该诊断是在原自适应路径上屏蔽似然项，不是遗漏信息过滤下的精确后验。更可信的当前结论是“全任务、参考和类型证据的联合使用改善了原 forced-only 估计器”，尚不能把类型融合本身写成普遍有效性定理。

## 数学、数值和停止边界

精确小样本参考使用有理数积分，对声明先验确实是连续参数联合后验。实际轨迹使用 32×32 Gauss-Legendre 积分；它不是精确连续后验。条件 empirical-Bayes plug-in 另行标注且只在同一记录上诊断，没有悄悄替代主臂。

在 Aligned-Full 的固定前缀/终点，32/64 阶的最大边际差为 0.0018835；64/256 动作固定前缀的差仅约 1.5e-5。事后在 Fused-Info 的全部 92 个已存储 64/256/终点前缀复核，32/64 阶最大差约 0.0015480，重算下一动作的 argmax 92/92 一致；边际差最大的五点，64/128 阶最大差约 5.4e-8。这支持本轮所查动作的数值稳定性，但不是所有实际更新的复算，也不是全局积分误差界。没有因此改动冻结策略或重新采样。

停止门始终在完整连续率模型上以 Fraction/向外 Decimal 区间计算，包含所有实际使用的任务、类型与参考观测。近似后验的数值误差不被当作停止证书。每个终点重算均与在线认证状态一致。认证条件依赖正确的 iid 模型、已知有限 s_g、风险在离线观测前固定、适应性选择的可预测性、忠实计数及审计过的 Python 算术契约；不推广为一般数值认证。

固定积分节点不满足原强制估计器的消失网格误差契约，新贪心信息准则也没有被证明跟踪原最优 KL 集。原证明加回原理不能直接迁移，停止证书本身更不能证明成本最优。故本轮不声称渐近最优、任意维度可扩展、Natural/真实对话有效性或 WWW 新颖性已通过审查。信息增益选查询属于已有方法思想。

## REVISE 的具体含义与停止点

1. 保留精确参考、融合模块、九臂对照和端到端认证接口；保留新分配器与全部正负结果。
2. 下一版若继续，先制定积分误差/自适应精度规则并验证对所有规划更新的影响；现有记录只用于诊断，不把 64/128 阶复算变成另一个获胜科学臂。
3. 在理论会话中单独处理 posterior/plug-in 的一致性、置信控制与新分配准则的目标错配。一步熵下降最优不等于 GLR 停止时间最优。无需为本轮有限成本结果虚构最优性证明。
4. 类型购买的独立效益和小 R 退化需要新的预定开发设计；目前不把“多源融合”和“类型报告单独贡献”合并成一个主张。后续实例/配置扩展、确认规模与是否继续均未在此执行。

本轮到此结束：在线 349056 = 324298 任务 + 24758 类型，逐策略离线计费 117504，总获取 466560；唯一共享离线观测 13056。主批次墙钟 884.28 秒，基础单测 25 项通过，另有精确信息分数与拒绝继续路径检查。模型、训练、GPU、付费 API 与确认世界均为 0。所有历史源码、结果收据及原确认协议保持不变。
