# Phase 1c: frozen development protocol (before any new Qwen generations)

Scope: identifiability plus benchmark feasibility, not a final method competition. Previous phase01 and UserBench outputs are immutable. No paid APIs, training, 35B or Phase 2. The user example stated 384, but 8 × 6 × 2 × 2 = **192**. Preserve these requested factors and cap this run at 192 new generations, no retries or substitute model. First 24 are included technical smoke; no accuracy-based smoke filter.

## Source gate and target adaptation

Use official ProofWriter 2020-12-03 OWA depth-3 TRAIN worlds only for this pilot. Native question lists are separately audited: after removing complement duplicates they are too sparse for the proposed pilot. The adapted target pool is the official complete `proofDetails` implication list; an independently written signed-Horn forward evaluator must match all original question labels AND the entire implication set in TRAIN and DEV. '~' is hard negation in OWA per official README. Unknown never becomes False.

For each eligible world choose six distinct positive atomic queries with three provable positives and three provable explicit negatives, at least two non-fact targets and disjoint fact-ancestor sets across all supported rule paths (in addition to disjoint chosen proof certificates). Label balance is a construction filter only; it does not prove independent θ priors. Do not call opposite statements separate targets. Source-based deterministic selection and ordering; target positions never alternate according to their labels. Hash-first eight eligible TRAIN worlds, independent of Qwen outcomes. Both formats and both repeats use the same complete facts/rules, claim, answer options, option order and output instructions. Only question header differs. Headers are a direct entailment question and a status-selection question. This is an adapted ProofWriter mechanism task, not native benchmark scoring or human preference evidence.

Each target's two repeats of one format have byte-identical prompts and fresh contexts, caches and independent seeds. Option order is identical between A/B for each target. Stratify option randomization by hidden truth solely during construction: equal correct-digit counts per world, 2/4 flipped targets in alternating worlds and equal order counts overall. Selection algorithms cannot read these labels. True labels are balanced within world. Report actual correct-position counts; do not move targets after seeing generation. Prefix first two targets use header pair 0; remaining four use paraphrase pair 1. This jointly tests cross-target/header transfer and cannot separate these effects.

Private world evidence goes to the respondent only. The selector is given group identity and previous canonical binary responses; it does not receive the source facts, gold labels, proof inventory, correctness or evaluation outcomes. If the learner were given the entire symbolic world it could solve it directly and elicitation would not be needed. Public target claims/metadata could still reveal difficulty, so a later metadata baseline remains necessary before a positive method claim.

ContractNLI is a zero-model application audit only this round: full document, 17 fixed hypotheses, retain E/C only and count NotMentioned separately. Shared evidence, imbalance and length are measured. Human annotations are not an independently executable truth system; no additional ContractNLI calls if ProofWriter fails.

## Generation

Use actual offline Qwen3.5-4B checkpoint at recorded path on idle physical GPU 3, one sequential process, float32 SDPA, TF32 disabled, temperature .7, top_p .95, top_k 0, thinking false, max_new_tokens 64. Answer-only digit 0/1. Strict parse; truncated or malformed answers invalid and scored incorrect. Fresh dialogue per response. Config and code/data hashes are frozen before loading. Stop at first infrastructure error or 3600 seconds. After 24 calls, continue only if all 24 attempted, no infrastructure error and at least 23 valid. Do not inspect accuracy for this gate. No calls beyond 192, retries, extra self-reports or testing alternate prompts.

## Unlabelled selectors and references

ETC: first two targets, two repeats in each format (8 calls); compare counts of within-format agreement, then use chosen format on remaining four. Tie: public precommitted group-hash coin. Repeat-and-Compare: same initial exploration; before each later target compare all previously observed within-format agreements, then use selected format for evaluation. The full grid includes both formats for earlier targets to update this replay. Invalid pair contributes zero agreement. Selectors accept only past canonical bits and group IDs. RR alternates A/B on the last four targets. Fixed A and B are required. Gold-labelled prefix selector is an explicitly unavailable-information reference. Hindsight best heldout format is optimistic evaluation-only oracle.

Primary diagnostic score: both responses' mean correctness from selected format on last four targets, 32 unique targets and 64 response scores per strategy. It is not 8-preference exact recovery. No majority decision with an arbitrary two-vote tie. Full grid 24 calls/world. Replayed ETC costs 16; Repeat-and-Compare with balanced past sampling costs 22; fixed/RR heldout cost 8. No equal-cost superiority claims. Enumerate all 8! prefix-to-test-group shuffles as negative diagnostic; include identity and ties, do not claim formal exchangeability.

## Analysis and stop decision

Freeze analysis before calls. Use 10,000 world-cluster bootstrap resamples (seed 2026103013), paired differences across strategies, no item-level pseudo replication. 8 worlds and 2 exploration targets have low power. Describe full A/B accuracy, prefix/heldout gaps, gap sign product, all group values, invalids, persistent wrong pairs, and label/position/header/depth strata. Do not define a type label and evaluate its prediction from the same observations.

Foundation requires all: (i) pooled accuracy's lower 95% bound > .5; (ii) mean product of prefix and heldout signed A−B gaps has lower bound > 0; (iii) ETC's paired gain over each Fixed A, Fixed B, RR and both constant-digit controls has lower bound > 0. These are conservative exploratory advancement gates, not a confirmatory test family or proof of the full Bernoulli assumptions. If any fails: REVISE_OR_NO_GO, no Phase 2. If all pass: REVIEW_ONLY_PENDING_TRIVIAL_BASELINES; direct-type and public-metadata checks still outstanding. No automatic Phase 2 even on positive data. Every world retained, including no-gap cases. No post-result prompt adjustment, replacement dataset or model, budget expansion or confirmation.

Exact Fraction Bernoulli tests are separate from natural language. They establish finite-design identifiability statements and boundary examples; they do not validate the full theory or imply LLM iid errors or common p/q.
