# 无标签可靠性的可辨识性：精确审计

本文件补充原 Theory_Note.md，不修改原定理或参数域。原模型的 θ 是未知固定符号；下面的均匀先验是用于构造不可辨识例子的额外假设。代码 `identifiability.py` 用 Fraction 穷举所有符号回答，未调用模型，也没有用 Monte Carlo 近似代替精确概率。

## 1. 每个目标 A/B 各一次

设 θ 独立且均匀，响应在给定 θ、类型和可靠率后独立。以 ±1 编码回答，A、B 的可靠率为 p、q，则

P(Y_A=a,Y_B=b) = [1 + ab(2p−1)(2q−1)] / 4。

交换 p、q 不改变联合分布。对任意多个独立均匀目标，联合分布仍然相同，因此这些无标签观察对 z 的信息为零。这个 Bayes 反例也排除了在任意固定 θ 向量上都成功的统一类型识别保证；它不声称每一种额外先验/约束都不可识别。已知非均匀先验，或目标间已知相关性，都可能打破对称。代码验证了先验 P(θ=+1)=3/4 的反例，以及两个目标共享同一 θ 的反例。

该结论针对这里的观察安排及类型识别，不是否定原模型允许重复查询时的恢复定理，也没有删除原理论中的独立标注参考流。

## 2. 同一形式独立重复两次

一致率 C(r)=r²+(1−r)²；在 r≥1/2 上单调，r>1/2 时严格递增。

C(p)−C(q)=2(p−q)(p+q−1)>0，条件为 p>q≥1/2。

对固定 θ，一致事件的概率仍是 C(r)，不需要随机 θ 先验。若跨目标的噪声也条件独立，组内一致次数可合并。未知可靠率时，可用 C 的单调性比较形式；这不等于已经证明最优的自适应查询分配。

在每题恰好两次 A、两次 B、已知 p/q、独立均匀 θ 的特定设计中，两个一致性指示量对 z 的似然比充分。均衡两类形式时，比较累计一致次数并在平局时均匀决策，是该设计下的 Bayes 类型判别。实验不能只对照弱 Round-Robin 而遗漏 Repeat-and-Compare。

例如 p=.75,q=.60：仅一对 A/B 的总变差距离为 0；两次各形式为 .105，单目标最优类型正确率仅 .5525。比较 2 个目标的一致次数，正确率 .5790；6 个 .6409；8 个 .6623；32 个 .8018。这里只是已知渠道参数的精确参考，不是未知参数方法的性能保证。8 组、2 题探索的开发测试很可能功效不足。

## 3. 持久错误与低于随机的渠道

令每个 (目标,形式) 先抽一次 U，之后所有回答均为 θU。重复调用仍可使用不同随机种子，但这种语义错误不会因此消失。在此模型里，重复任意次仅相当于 A/B 各一次，均匀独立 θ 下交换类型的总变差距离为 0。代码验证 AABB 的精确分布相同。

此外 p=.8,q=.2 时 C(p)=C(q)，交换类型可用 θ 反号吸收；两次各形式仍无法识别。整体平均准确率超过 .5，不能保证每个目标、每个形式都处于原模型的可靠率参数域。

## 4. 对自然语言实验的约束

- 同一对重复保持 prompt、选项顺序和解码配置相同，只改变独立采样种子；否则观测的不是同一渠道。
- 一致性与正确率分开，报告“双次一致但都错”的比例和无效输出。
- θ/证明/评测正确率只进入离线评分，不能进入形式选择器。选择器只接收历史答案及不含真值的 ID。
- 组内多题及不重叠的某个证明证书，只是结构筛查；不证明噪声独立、共同 p/q 或共享 z。
- Bernoulli 精确结果与自然语言观察分开报告；小预算开发数据不能证明渐近最优或人类行为。
