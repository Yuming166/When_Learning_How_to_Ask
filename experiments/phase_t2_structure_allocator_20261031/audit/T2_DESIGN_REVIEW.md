## Frozen teacher and stopping limits

Phase2e's final decision is REVISE. Its full-evidence fusion has bounded positive development signals, but neither Fused-Original nor Fused-Info is confirmed optimal or a default promoted main method. Fused-Original inherits the original coefficient architecture, replacing its forced-only estimator with posterior means and marginal MAP group types. The actual posterior uses fixed 32-by-32 Gauss-Legendre quadrature. The coefficient solver is float64 cutting-plane LP plus analytic separation, supports G<=2, and retains tolerance floors. These are numerical computations, not interval-certified optimal allocations.

Fused-Info's delayed greedy answer-information objective is distinct from the KL coefficient and from stopping-time minimization. Its native cadence differs from a fixed block-32 wrapper. The same distinction applies to native Fused-Original and the matched teacher. Both native and matched identities must remain visible.

The certified gate independently profiles the complete continuous-rate likelihood, including all task, type and reference observations. Its inherited arithmetic scope is d<=4, total observations<=2^50, finite known type accuracies, faithful counts and the declared Fraction/Decimal arithmetic contract. Under the correctly specified independent Bernoulli model and predictable sampling it certifies an accepted output; it does not certify a posterior, LP optimum, neural approximation, termination time, or a family-wide risk bound across many arms. No approximate information score or neural confidence may replace it.

## Required T2 source checks before scientific execution

1. Separate fresh worlds by complete histories across train, validation, offline strata, budget development and final closed-loop evaluation. Freeze dimensions, partitions, parameter combinations, calibration ratios, states and all three fits before generating seeds. Preserve failures without replacement or scientific retries.
2. Keep only observable counts, calibration summaries, public group structure/risk/budget, and estimates computed from those observations in network inputs and losses. Neither truth, seed, split identity nor evaluator reward may enter. Posterior features require their own charged online estimation time.
3. Continuous masked action weights replace integer labels. DeepSets fact/group permutations must transform outputs consistently; tests must include nonsymmetric values and unequal groups. Teacher argmax tie conventions do not prove network equivariance. Scientific scope remains d<=4 and G<=2 even if tensor code accepts more shapes.
4. For nonsymmetric per-action neural allocations, evaluate every wrong answer vector and all type alternatives. The symmetric coefficient solver's one-flipped-fact-per-group reduction cannot be transferred without its symmetry assumptions. Compute radial K at fixed calibration intensity alpha, solving the nonlinear radial information constraint; 1/min-information is wrong when alpha>0. Distinguish finite frozen training cuts from all-alternative diagnostic evaluation and from an exact regret theorem.
5. Use one common forced schedule, tracking rule, fixed block-32 target-update cadence and check-32 stopping cadence for matched arms. Preserve the native teacher separately. Original T1 MLP remains frozen and d=4 only. Warm-started KL must recompute changed-state cuts and preserve the cold solver's acceptance checks; stale weights are not an exact solve.
6. Select the two fixed-budget readouts using only separate budget-development teacher/simple-baseline outcomes at the frozen candidate budgets. Do not inspect student outputs for budget selection. Freeze the selection receipt before final evaluation. A confidence trajectory's intermediate guesses are not optimized for a known early deadline; never substitute a future terminal answer into an earlier budget. If certified earlier, absorb its already available answer and charge actual min(T,B).
7. Charge offline references to every scientific arm, and report unique shared acquisition separately. Include posterior estimation, solver, network preprocessing/inference, scheduler, profile checks, certificate work, initialization, teacher-data generation, fitting and diagnostic compute without double counting. Distinguish neural-forward speed from end-to-end planning and full-path speed. Cache use and warmup must be disclosed and comparable.
8. Keep every planned path in denominator/accounting tables, including failures and uncertified caps. A cap guess is not a certified recovery. Pair on whole worlds and cluster reused risks/readouts by world when pooling. Small stratified resampling intervals are descriptive. Query-cost ratio <=1.05 and planning speedup >=2 are development targets; an inconclusive comparison supports REVISE rather than a noninferiority claim.

## Initial implementation observations

The inspected t2/core.py preserves the original square exploration and cumulative tracker via Scheduler and reproduces the frozen teacher's requested tolerance, two numerical attempts, minimum-information and gap acceptance checks. The initial observed_state helper set every action mask bit to one even when type actions are unavailable; this was corrected before freeze. The planned finite-s worlds avoid that branch, and the documented observable boundary now also handles unavailable type actions.

The inspected information source enumerates `(2**d-1)*2**G` alternatives, complements the appropriate task means, analytically profiles ordered alternative rates and solves the radial root while alpha remains fixed. It explicitly detects uncovered-fact/infinite-cost directions. Its training cuts include base rate pairs and adversaries at teacher/uniform radial allocations; these are a finite relaxation. The warm solver only reuses adversarial rate locations and recomputes coefficients and separation at fresh p/q/alpha/s; it does not reuse solved weights or rounded parameter keys.

The inspected DeepSets source uses shared fact encoders, group sums, a global sum and shared action heads, with padded facts/groups excluded by masks. All inputs come from the common whitelist. Both DeepSets objectives have the same architecture; the fresh MLP receives the same observable feature content. Cut/target type slots are remapped after batch padding, and unused cut rows use offset one. The information loss is KL plus the positive finite-cut radial ratio excess with a 1e-10 denominator floor; this floor is optimistic for zero-information directions and must remain disclosed. The source contains one CPU fit per kind and a final checkpoint only. The caller verifies the training freeze, refuses an existing training directory, writes a single-attempt receipt, and measures data loading and whole-fit/save wall/CPU time outside the narrower inner fit timer.

Additional initial data-source findings were sent to the author before generation: (a) the collector reset the planning clock at every label snapshot, creating additional teacher behavior updates beyond block32; (b) `behavior=i%3` was perfectly aliased with risk because R is the fastest grid index and the traversal step is 37; (c) the behavior called `drrc` was posterior-mode greedy task allocation without the frozen D-RRC workload threshold. These were corrected before freeze; no generated data were used to identify them.

The next source inspection confirms the unavailable-type mask follows known_s, snapshot target injection is guarded by `needs_update()`, and the third data behavior is named `mode_task`. An initial behavior correction to `(i//3)%3` removed risk aliasing but created exact calibration aliasing; this was also caught before generation. The final version assigns behavior using a separate fixed namespace/split/index hash. The static plan test checks all behavior-by-risk, behavior-by-alpha, behavior-by-partition and behavior-by-rate combinations. The author extended the last snapshot before freezing, preserving six states per world at 2d,16,32,64,256,1024. Protocol, configuration and collector agree. Counts and posterior concentration after t=1024 remain outside the saved history-length range; the protocol states that limit. Any resulting offline/online gap would remain compatible with distribution shift and would not uniquely identify an architecture or objective defect.

Source inspection of the mathematical and neural unit tests finds substantive independent checks, including SLSQP minimization against the analytic all-alternative solver, the fixed-alpha reciprocal counterexample, fresh-rate warm/cold agreement, noncontiguous fact/group permutations, padding, masking and nested hidden-field rejection. The reviewer inspected the author-produced pre-generation log: **41 tests PASS in 2.268 seconds** (four core, fifteen information, thirteen evaluation, nine neural). The reviewer did not execute these tests. These deterministic/synthetic checks establish source contracts, not scientific effectiveness.

Evaluation-source inspection confirms the literal frozen Phase2e floating precheck and independent strict gate at crossings/cap, check32 cadence, separately labeled native teacher, matched initial2d-plus32 cadence, observable-only predictor calls, T1 d4-only handling, and fixed-budget absorption using only the current certified answer. No future terminal answer is substituted at an earlier readout. Per-component timing measures wall time, with total process CPU measured separately; descriptions must preserve that distinction. A durable progress callback now emits paid-prefix blocks before costly operations and scheduled checks; the driver supplies per-path journals. The generator persists completed-world manifest progress and explicitly marks a failed current world's unrecorded partial cost unknown. Unexpected worker failures also carry unknown-partial-cost status. Such records cannot support complete cost claims.

The reviewer found and the author removed an unused import of a nonexistent T1 conversion helper in the offline driver before freezing. The driver now marks evaluation completed only with all 858 records, zero failed paths and exactly six expected nonapplicable records; otherwise it records incomplete. The separate expected manifest retains the missing method denominators if a world/risk job ends early. Analysis must fail visibly on missing coverage, not report a completed-pair-only success. The current audit approves preparation and source boundaries; later runtime and analysis review remains necessary.

## Claim boundary

A successful T2 run would be bounded evidence about computation/query tradeoffs in the declared QRelBench-Exact development grid. It would not establish that DeepSets is novel, that more neural complexity is useful, that the teacher is asymptotically optimal, that the neural policy inherits allocation optimality, or that Natural, human-user or Web effectiveness has been demonstrated. The user-authorized stopping point is the bounded GO / REVISE / NO-GO report with all historical results preserved.
