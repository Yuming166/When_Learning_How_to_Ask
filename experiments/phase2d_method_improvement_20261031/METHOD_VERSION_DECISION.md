# Phase 2d P0：方法版本与研究判断

2026-10-31。**本轮指定的 2×2 消融和停止认证已完成；任务分配优化的独立价值得到受控开发数据支持，对主动类型基线的剩余优势较小且有不确定性。允许保留新的认证候选版本，不将其升级为已确认或已证明完整理论最优的方法。**

## 结果来自哪里

一次冻结开发批次：d=4，分组 [1,3]/[4]，alpha=0/3，R=16/64/256/1024，p=.85、q=.60、已知 s=.8。16 个单元，每单元 4 个独立世界，世界内四策略配对，共 64 世界、256 轨迹。全部完成，0 删失、0 错误浮点停止输出；后者不能经验验证 exp(-R) 级风险。

主批次在线动作 688,816，逐策略计费离线观测 261,120，总获取 949,936；唯一离线观测 65,280。墙钟 1103.29 秒。主采样保留共同的旧浮点停止规则以隔离采样消融；全部终点另行通过区间认证，四条 R1024 路径实际集成认证重放。以上仍是开发样本，不是自然语言 Qwen/人类可靠性证据或独立确认结果。

## 1. 没有类型询问，任务分配优化还有价值吗？

有，限于当前测试范围。R1024 的 [1,3] 单元如下，数值为在线动作均值除以 R，越小越好：

|alpha|Aligned-Full|Aligned-NoType|D-RRC-Type|D-RRC-NoType|
|---:|---:|---:|---:|---:|
|0|7.1719|8.1016|7.8203|15.4453|
|3|6.2031|7.6484|6.8984|14.6250|

禁用类型动作后，Aligned-NoType 对 D-RRC-NoType 的在线成本均值下降 **47.55% / 47.70%**。对应配对差 D-NoType−Aligned-NoType（单位 /R）的探索性 95% 区间分别为 7.3438 [7.1250,7.5625] 与 6.9766 [6.5156,7.4922]。同一分组的其余 R 单元也保留正任务收益；没有挑选或删除其余单元。

百分比是“单元平均成本的比值”，不是逐世界百分比的平均；区间是预定的绝对配对差区间，不是百分比区间。全部区间采用 4000 次世界内配对 bootstrap，n=4、未作多重比较校正，仅作探索描述。

## 2. 简单基线能主动询问类型后，还剩多少优势？

同一 R1024、[1,3] 单元中，Full 对主动 D-RRC-Type 的在线均值成本优势降为 **8.29% / 10.08%**，配对 /R 差分别为：

- alpha0：0.6484，95% 区间 **[-0.0703,1.2188]，跨零**。
- alpha3：0.6953，95% 区间 [0.1719,1.0625]，仍是小样本开发证据。

加计共同离线成本后，alpha3 的总获取成本优势为 **5.39%**，不可把在线 10.08% 直接称作总成本下降。旧式 Full 对无类型 D 基线的同批在线优势为 53.57% / 57.59%；不能继续将这些数字表述为相对 type-aware 强基线的优势。

因此两种说法应同时保留：“任务分配有独立价值”与“很大部分原比较差距可被简单的主动类型购买缩小”。四策略的收益不是可相加的任务/类型因果份额，不报告归因百分比分解。

## 3. 新基线够强吗，有哪些失败？

D-RRC-Type 持续按 R 尺度类型证据目标与任务工作量分配购买；不是每组问一次或任意限制类型比例。它与其他三策略共享 forced-only 估计、探索、网格、跟踪、GLR 和计费，但属于一条预先指定的启发式规则，不宣称穷尽所有强基线。

它在 [4]、alpha3 的所有 R 都比 D-NoType 更贵。R1024 时分别为 6.0781 与 5.1406，类型/R 为 1.1450；Full 类型/R 仅 0.1304。这说明该规则会过买类型报告，不能只用 Full 对它的优势宣传普遍改进。低 R 下 Full 也未稳定优于所有对照，例如 [1,3]、alpha0、R64 中 Full 12.7500、D-Type 11.6250。

[4]、alpha0 的 D-Type 按冻结前公开结构规则直接退化为 D-NoType，其相同路径是构造结果。四臂在此批次成本均相同，与零领先阶溢价方向一致；不把它升级为有限 R 类型信息无用定理或所有浮点实现逐位相同的证明。

计算效率仍是限制：R1024、[1,3] 中 Full 每轨迹平均 CPU 18.86/17.55 秒，D-Type 为 2.12/1.99 秒。Full 节省查询不等于节省 CPU。本轮按用户范围没有实现求解加速或新增不确定性策略。

## 4. 停止认证补上了哪一步？

新门使用精确有理数连续剖面和向外区间，只在候选下界减全部错误答案上界严格超过阈值上界时接受。已知旧浮点误判被拒绝；509 个旧非 Oracle 终点及 256 个新终点均被认证。四条 R64 浮点路径准确重放，四条 R1024 在线认证路径在原终点认证，额外查询均为零。

这闭合了声明有界输入与数值后端契约下的停止算术蕴含。原 iid 模型的错误认证输出风险可保守地转移到该门；它不补上浮点优化器的无限时域误差、所有采样器最终停止或完整可执行渐近最优性。详见 `CERTIFIED_STOPPING_REPORT.md` 与独立的 `STOPPING_PROOF_AUDIT.md`。
