# Phase 2d P0：停止认证结果

2026-10-31。结论：**有界原型的数值停止蕴含已通过审计；尚未证明完整可执行算法的无限时域最优性。** 本报告对应 `CERTIFICATION_VALIDATION.json`、`CERTIFIED_STOPPING_SPEC.md`、`STOPPING_PROOF_AUDIT.md` 和 `artifacts/certification/`，原 Phase2c 代码、结果、确认协议不变。

## 认证了什么

对给定候选答案 c，精确枚举所有答案/组类型，并以有理数求解连续可靠率的受序约束极大似然。对数和后续计算使用向外舍入区间；接受条件为：

\[
\underline F(c)-\overline{\max_{\theta\ne c}F(\theta)}
>\overline{\beta},\qquad
\beta=R+2\log(M+1)+\sum_{j,m}\log(N_{jm}+1)+\sum_g\log(K_g+1).
\]

下界不能超过候选真实剖面值，上界必须覆盖全部错误答案及连续可靠率。区间重叠、数值异常或达到预算而未认证时，继续或弃答，不能以浮点判断兜底。仅提高计算精度不满足这个条件。

输入浮点数按其精确二进制值解释；先转成有理数再计算 `1-eta` 和 `1-s`。声明支持 d≤4、总观测≤2^50，默认精度序列 50/80/120 位。原型依赖所列模型假设、精确整数/有理数运算以及 Python Decimal/libmpdec 的舍入契约；不是证明助理验证的程序。实际运行版本见 `RUNTIME.json`。

在原 iid 模型、预先固定 R 和边界、合法适应性采样与调用设置下，该门保守地恢复原模型级的“错误认证输出概率≤exp(-R)”蕴含。它不提供给定某次校准样本后的条件风险保证；也不保证所有采样器最终停止、浮点优化器任意时域精确或固定预算成本已渐近最优。预算末尾用于计分的猜测与认证输出明确分开。

## 反例与拒绝行为

保留的反例：单偏好，第一形式全部为正回答，n=1,000,000,000,152，eta=1/8，无参考/类型报告，输入浮点 R=559615787992.8533。精确量为：

\[
g=n\log(7/4),\qquad \beta=R+\log(n+1).
\]

旧浮点实现得到 g−beta=0.0001220703125，大于旧保护量约 2.8631e-7，错误通过数值门。新门包围的精确残差约为 **−0.0000065633837993682**，返回 `rejected`。这是静态算术反例，不是实验中观察到的概率风险违例；全部原始端点见 `artifacts/certification/counterexample.json`。

集成测试还强制制造首次 `undetermined`：采样从 16 继续到 32 后才接受；一直未定的路径到 64 动作时弃答，`strictly_certified_output` 为 null。异常中断前的观测及成本也被保留。这些是工程拒绝行为检查，不是新增科学样本。

## 证据强度与剩余工作

39 项测试通过；另有独立的 2,352 项有理数最优性支撑梯度检查、27 项有理数对数级数包围检查、5 个联合似然 fixture / 28 个答案剖面、21 个非法输入检查，以及环境 Decimal 设置、低精度重叠、精度细化与故障注入检查。独立审查先推导证明义务再读新实现；审查来自分开的同家族原生代理，不称外部专家、跨模型或形式化证明。

**765 个终点通过包围，只说明这些终点满足保守停止条件。** 终点审计不能代替带认证门的前瞻性完整实验。新门对浮点候选不要求精确，但不能弥补采样优化器的任意时域近似、未知分布失配或原模型假设错误。本轮没有采用更锐利的混合边界，没有加速求解器，也没有启动确认集。

因此可将“Aligned-Full 原采样器 + 本认证门”登记为新的有界候选方法；其成本、功效及停止性需要新版本的前瞻协议，不能继承旧 Phase2c 确认计划的证据身份。具体决策见 `METHOD_VERSION_DECISION.md`。
