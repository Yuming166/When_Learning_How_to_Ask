# W2a：已知通道下的受控来源依赖——证明与边界

状态：**已证明、精确小规模交叉核对；仅限明确构造的概率模型**。本文件是 W2a 冻结协议的数学实现说明。没有模型调用、网页请求、训练或人工验证。旧 W1/W1.1 未修改。

来源饱和、数据处理不等式、二元对称通道和多数票风险是既有机制/标准工具，本文件不将它们包装成新的研究贡献。新增可报告产物是：在这个指定模型中，把三读风险差、非退化参数矩形、访问费翻转区间和错置信反例写成可核对的显式证书；不据此宣称文献新颖性或继承此前未知可靠性理论的渐近最优性。

## 1. 完整前提与记号

单个目标事实 \(\theta\in\{-1,+1\}\)，先验均匀。构造的根 \(i\) 产生一次持久报告
\[
 V_i=\theta B_i,\qquad \Pr(B_i=+1)=r.
\]
不同根的 \(B_i\) 相互独立，且独立于 \(\theta\)。第 \(k\) 次读取根 \(i\) 返回
\[
 Y_{ik}=V_i E_{ik},\qquad \Pr(E_{ik}=+1)=a.
\]
全部 \(E_{ik}\) 相互独立，也独立于所有根错误和真值。参数 \(r,a\in[1/2,1]\) **已知**；这是观测通道假设，不是 Qwen 的实测可靠率。来源共享关系已知，URL 标识不另含事实信息。

每次激活一个新根花费 \(c\ge0\)，每次读取花费 \(\ell>0\)。复制页面共享同一个 \(V_i\)，但基础模型允许每次读取新的条件独立 \(E\)。副本打开费在基准中为零；下文另论非负附加费。任一策略只见已知参数、已声明来源图和回答，不见 \(\theta,B,V,E\) 的实现值。

所有风险指均匀先验下的最优 0/1 Bayes 错误概率；平票随机各半。自然网页不同域名是否独立、真实读者错误是否独立、真实访问成本是多少，均不由这些前提证明。

定义
\[
 x=2r-1,\quad y=2a-1,\quad
 t=ra+(1-r)(1-a)=\frac{1+xy}{2},
\]
\[
 S_n(p)=\Pr\{\mathrm{Bin}(n,p)>n/2\}
       +\tfrac12\Pr\{\mathrm{Bin}(n,p)=n/2\}.
\]
取 \(S_0(p)=1/2\)。

## 2. 同根重读与复制页面：实验等价，而不是新增独立来源

**命题 1。** 对同一根，任意固定 \(n\) 次重读和任意 \(n\) 次复制页面读取，在上述相同通道、相同成本条件下诱导完全相同的 \((\theta,Y_1,\ldots,Y_n)\) 联合分布。因此其 Bayes 风险、互信息、任意由回答计算的统计量分布都相同。

**证明。** 给定 \(V=v\)，两种操作的回答联合律均为
\[
 \Pr(Y_1=y_1,\ldots,Y_n=y_n\mid V=v)
 =\prod_{k=1}^n
 a^{\mathbf1\{y_k=v\}}(1-a)^{\mathbf1\{y_k\ne v\}}.
\]
再对相同的 \(\Pr(V\mid\theta)\) 混合，即得相同联合律。URL 名称只是已知的根标签重命名。对自适应的副本选择/停止规则，也可逐步将每个副本动作替换成重读同根，耦合相同的 \(E_k\)；由归纳，每一步的观测历史及决策分布一致。证毕。

**成本推论。** 若复制动作另付非负打开费，重读策略可用不更多的成本模拟复制策略。故在相同预算下，复制页面没有更小最优 Bayes 风险的保证，并被这类可模拟重读弱支配。零附加费时等价；正附加费不保证严格劣，因为可能存在预算余量或信息增益已经为零。

前提不可省：若两个副本读取通道不同，或复制保留了同一个持久抽取错误而重读没有，或页面元数据另含真值信息，这一等价性并未建立。

## 3. 两种指定策略的精确 Bayes 风险

**命题 2。** 一个根读取 \(n\) 次，与 \(n\) 个独立构造根各读一次，分别有
\[
 \boxed{R_{\rm rep}(n)=r-(2r-1)S_n(a)},\qquad
 \boxed{R_{\rm fresh}(n)=1-S_n(t)}.
\]

**证明。** 同根时，若 \(k\) 个回答为 \(+1\)，记
\[
 u=a^k(1-a)^{n-k},\quad v=a^{n-k}(1-a)^k.
\]
似然比为 \([ru+(1-r)v]/[(1-r)u+rv]\)。当 \(r,a>1/2\) 时，其大于 1 当且仅当 \(k>n/2\)，故多数票是 Bayes 决策。多数票恢复 \(V\) 的概率为 \(S_n(a)\)。最终恢复 \(\theta\) 的概率为
\(rS_n(a)+(1-r)[1-S_n(a)]\)，给出第一式。边界上的无信息/平票情形由同式直接成立。

独立根情形每个回答相对 \(\theta\) 的正确率是 \(t\)，且给定 \(\theta\) 后相互独立；多数票正确率因此为 \(S_n(t)\)。证毕。

**偶数性质。** 对 \(k\ge1\)，随机平票时 \(S_{2k}(p)=S_{2k-1}(p)\)。证明：从 \(2k-1\) 到 \(2k\) 只会把原差一票的结果变成平票；改变正确率的两个项为
\(\tfrac12p\Pr(K=k-1)\) 与
\(-\tfrac12(1-p)\Pr(K=k)\)，其中 \(K\sim\mathrm{Bin}(2k-1,p)\)。二项式系数相同，两项抵消。

这个偶数等式针对上述对称先验、同通道和 0/1 风险；不表示偶数观测没有任何信息增量。

## 4. 来源上限及非新颖性的定位

由 Markov 链 \(\theta\to V\to Y_{1:n}\) 和数据处理，
\[
 I(\theta;Y_{1:n})\le I(\theta;V)=\log2-h(r),
\]
其中 \(h(p)=-p\log p-(1-p)\log(1-p)\)，单位为 nats。

还可以直接写出任意同根观测历史 \(H\) 的后验：
\[
 \Pr(\theta=+1\mid H)
 =(1-r)+(2r-1)\Pr(V=+1\mid H)\in[1-r,r].
\]
历史可以含非预知的自适应停止和副本动作，只要它们仍不包含 \(V\) 之外的新真值证据。故任意同根历史的最大真实后验不超过 \(r\)，Bayes 风险至少 \(1-r\)。这正是已有的持久来源错误饱和机制，不是一个新增 WWW 定理。

当 \(a>1/2\) 时，强大数律使无限读取恢复 \(V\)，于是
\[
 R_{\rm rep}(n)\longrightarrow1-r,\quad
 I(\theta;Y_{1:n})\longrightarrow\log2-h(r).
\]
信息极限可由有限字母后验熵的有界收敛得到。相反，若 \(r,a>1/2\)，独立根的 \(t>1/2\)，故
\(R_{\rm fresh}(n)\to0\) 且互信息趋于 \(\log2\)。

边界必须保留：

| 参数 | 同根重复 | 独立根 |
|---|---|---|
| \(r=1\) | \(R=1-S_n(a)\) | 相同风险与联合观测律；激活成本仍可能不同 |
| \(a=1,\ n\ge1\) | 第一次已见 \(V\)，风险 \(1-r\) | 风险 \(1-S_n(r)\) |
| \(r=1/2\) 或 \(a=1/2\) | 风险 \(1/2\)，信息为零 | 同样无信息 |
| \(r=a=1,\ n\ge1\) | 风险零 | 风险零 |
| \(n=0\) | 风险 \(1/2\)，信息为零 | 相同 |

只有根可靠性已知为 \(r=1\) 才得到第一行；不能用平均估计接近 1 替代确定的无来源错误假设。

## 5. 三读严格优势及显式非退化区域

**命题 3。** 对 \(1/2<r<1,\ 1/2<a\le1\)，相同三次读取下，三个独立根严格优于同根三读：
\[
 \boxed{\Delta_3=R_{\rm rep}(3)-R_{\rm fresh}(3)
       =\frac{x(1-x^2)y^3}{4}>0.}
\]

**证明。** \(S_3(p)=3p^2-2p^3\)，故
\(2S_3((1+z)/2)-1=(3z-z^3)/2\)。
带入命题 2，线性项 \(3xy\) 抵消，剩余
\((xy^3-x^3y^3)/4\)。严格符号由 \(x\in(0,1),y>0\) 得到。证毕。

**显式区域。** 在闭矩形
\[
 \boxed{r\in[2/3,5/6],\quad a\in[3/4,9/10]}
\]
内，两种通道都有非零、非随机猜测的误差，且
\[
 \boxed{\Delta_3\ge1/108.}
\]
因为 \(x\in[1/3,2/3]\)，凹函数 \(x-x^3\) 的最小值在端点，至少 \(8/27\)；又 \(y\ge1/2\)，因此下界为
\((8/27)(1/8)/4=1/108\)。
这是覆盖整个矩形的解析证明，有限网格检查不是区域证明。

这只比较两个指定策略的三读风险，不声称所有 \(n\) 的排序、不声称自适应全局最优，也不把人工构造根的独立性推广到真实网页。

## 6. 明确的访问费翻转区间：相同读数不等于相同预算

三读方案的成本分别为
\[
 C_{\rm rep}=c+3\ell,\quad C_{\rm fresh}=3c+3\ell.
\]
所以命题 3 在 \(c>0\) 时不是同成本结论。若比较惩罚损失 \(R+\eta C\)，\(\eta>0\)，三根方案严格更优当且仅当
\[
 c<\Delta_3/(2\eta);
\]
等号为平局。该式只是两个固定方案的比较。

还可给不依赖成本惩罚系数的预算证书。固定 \(B=4\ell\)，比较：

- Repeat：激活一个根并尽可能读取，读数 \(n_{\rm rep}=\lfloor(B-c)/\ell\rfloor\)。
- Fresh：每根只读一次并尽可能激活，根数 \(n_{\rm fresh}=\lfloor B/(c+\ell)\rfloor\)。

仅考虑 \(0\le c\le\ell\)，两策略都有可用观测。

**命题 4。** 若 \(1/2<r<1,\ 1/2<a<1\)：

1. \(0\le c\le\ell/3\)：两策略各得到三次或四次观测，偶数性质使其风险等于各自三读风险，故 Fresh 严格优。上述矩形内优势至少 \(1/108\)。
2. \(\ell/3<c\le\ell\)：Repeat 得到三读，Fresh 只有两个独立根；\(S_2(t)=t\)，故
   \[
   R_{\rm fresh}(2)-R_{\rm rep}(3)
   =x[S_3(a)-a]
   =\frac{xy(1-y^2)}4>0.
   \]
   Repeat 严格优。上述矩形内优势至少 \(3/125\)。

第二个下界使用 \(x\ge1/3\)，且凹函数 \(y-y^3\) 在 \([1/2,4/5]\) 至少为
\(\min(3/8,36/125)=36/125\)。所以差至少
\((1/3)(36/125)/4=3/125\)。

阈值来自整数预算的可行性变化；是明确、可复现的策略翻转例，不能称整个最优策略的普适阈值。混合根数/深度或自适应策略可以优于两个端点方案。

例：\(r=3/4,a=4/5,\ell=1,B=4\)。

| \(c\) | Repeat 读数 | Fresh 根数 | Repeat 风险 | Fresh 风险 |
|---:|---:|---:|---:|---:|
| \(0\) | 4 | 4 | \(151/500=.302\) | \(1127/4000=.28175\) |
| \(1/4\) 或 \(1/3\) | 3 | 3 | \(.302\) | \(.28175\) |
| \(1/2\) 或 \(1\) | 3 | 2 | \(.302\) | \(7/20=.35\) |

## 7. 将 URL 错当独立根：置信失败不必改变固定读数准确率

考虑一个根给出 \(n\) 个同向 \(+1\) 回答。真实后验为
\[
 p_{\rm true}(n)
 =\frac{ra^n+(1-r)(1-a)^n}{a^n+(1-a)^n}
 =\frac{r+(1-r)\kappa_n}{1+\kappa_n}\le r,
 \quad \kappa_n=((1-a)/a)^n.
\]
对 \(a=1\) 按 \(\kappa_n=0\) 解释。若误把每个 URL 当独立根，而仍正确使用单次边际正确率 \(t\)，则
\[
 p_{\rm URL-iid}(n)=\frac{t^n}{t^n+(1-t)^n}\longrightarrow1
\]
（\(r,a>1/2\)）。这隔离了依赖建模错误，不需要故意给错单次准确率。

若 \(1/2<r<1,\ a>1/2,\ \delta\in(0,1-r)\)，取
\[
 n\ge\left\lceil
 \frac{\log((1-\delta)/\delta)}
      {\log(t/(1-t))}
 \right\rceil,
\]
则错模型可报告至少 \(1-\delta\) 的置信，而真实后验至多 \(r<1-\delta\)。真实条件错误率至少 \(1-r\)，不是错模型声称的至多 \(\delta\)。

精确例 \(r=3/4,a=4/5,n=5,\delta=.05\)：
\[
 p_{\rm true}=3073/4100,\qquad
 p_{\rm URL-iid}=371293/388100>.95.
\]
同向正回答事件概率为 \(41/250\)；任一同向符号的事件概率为 \(41/125\)。真实错误约 \(25.05\%\)，错模型报告约 \(4.33\%\)。这些是精确事件概率，不是重复样本的估计或显著性检验。

**固定 \(n\) 的负面边界。** 同根同通道时，真实 Bayes 和错误 URL-iid 的 0/1 决策都为多数票，所以固定 \(n\) 准确率完全相同。该诊断展示失准的置信，不能直接包装为准确率提升。

**并非只靠全同向事件。** 当 \(r,a\in(1/2,1)\)，条件于 \(V\)，强大数律给出
\(n^{-1}\sum_kY_k\to V(2a-1)\)。
错模型的对数后验比为
\(\sum_kY_k\log(t/(1-t))\)，因此它对实际报告 \(V\) 的置信几乎必然趋 1。真实模型对 \(V\) 为真值的置信仅趋 \(r\)。在 \(V\ne\theta\) 的概率 \(1-r\) 上，错模型最终高度自信地错。这个渐近描述不自动给出任意首次越界停止规则的有限样本错误率。

## 8. 抽取独立性违例控制

若把每次独立 \(E_{ik}\) 改为根内持久 \(U_i\)，即所有读取都为
\(Y_{ik}=V_iU_i\)，\(\Pr(U_i=+1)=a\)，则根内重读完全不增加信息：
\[
 R_{\rm rep}(n)=1-t\quad(n\ge1),\qquad
 I(\theta;Y_{1:n})=\log2-h(t).
\]
若不同根的 \((B_i,U_i)\) 仍独立，Fresh 风险继续为 \(1-S_n(t)\)。证明是同根所有回答都等于首次回答，而每根首次回答仍是正确率 \(t\) 的二元通道。不能把主模型的 \(S_n(a)\) 降错公式应用到该控制；这是对假设敏感性的检查。

## 9. 精确核对与可复算说明

附带 `theory_certificates.json` 记录：

- \(r\in\{1/2,2/3,3/4,5/6,1\}\)；
  \(a\in\{1/2,3/4,4/5,9/10,1\}\)；
  \(n=0,\ldots,5\)：150 个配置。
- 每个配置分别完全枚举 \(\theta\)、所有 \(B\)、所有 \(E\)，共300个观测律质量归一化检查；用
  \[
    R^*=\sum_{\boldsymbol y}
       \min\{\Pr(\theta=-1,\boldsymbol y),
              \Pr(\theta=+1,\boldsymbol y)\}
  \]
  独立计算 Bayes 风险，与命题 2 的两个闭式全部精确相等。
- 25 个三读参数点的因式分解精确成立；偶数等式、误置信分数、两种区域下界和访问费边界例均通过有理数断言。
- 计算使用 Python `Fraction`；没有 Monte Carlo 误差。这个辅助有理数网格核对公式，不替换或调整 PROTOCOL 中冻结的性能网格。区域证书依靠上述解析凹性证明，网格只是实现交叉核对。

独立枚举器的核心如下；它不使用多数票公式来产生风险，因而不会仅重复被检验公式：

~~~python
from fractions import Fraction as F
from itertools import product
from collections import defaultdict

def enumerate_risk(r, a, n, fresh):
    law = defaultdict(lambda: [F(0), F(0)])
    for ti, theta in enumerate((-1, 1)):
        for bs in product((-1, 1), repeat=n if fresh else 1):
            pb = F(1, 2)
            for b in bs:
                pb *= r if b == 1 else 1-r
            for es in product((-1, 1), repeat=n):
                prob = pb
                for e in es:
                    prob *= a if e == 1 else 1-a
                ys = tuple(theta * (bs[i] if fresh else bs[0]) * es[i]
                           for i in range(n))
                law[ys][ti] += prob
    assert sum(sum(v) for v in law.values()) == 1
    return sum(min(v) for v in law.values())
~~~

这里建立的是理论—实现对应和明确反例。没有证明自然网页存在同样的 \(r,a\)、真正独立根、可交换副本或对应的读取成本；也没有证明未知可靠性、学习型查询 Agent 或真实 Web Method 的性能。
