# Python 与 LLM 测试方法

## 任务和推荐策略

目录商品具有 neckline、sleeve_length、fabric、wash_care、pattern 五种属性。构造顾客为每种属性值赋予偏好分数，并给出洗护/面料硬约束及购买门槛。合格商品的分数为五项偏好之和；最高分严格大于门槛时应购买任一并列最优商品，否则应NO_BUY。Python与独立SQLite评价器在完整本地实验中核对真值。

策略只看公开菜单、独立先验和已询问字段的回答。隐藏画像和评价器目标不进入选问。六个问题分别询问五个属性字段和purchase_threshold，每问题成本为1。问题预算0–6；预算5是历史主比较，3和4辅助报告。

同池先验固定为2048个构造偏好样本，共12288个；它们不计作评价顾客。原实现将已知字段覆盖到每个先验样本，再计算每个样本下的可接受决策集合；没有按答案匹配过滤样本。最终推荐最大化先验样本上的正确决策比例，并列时优先NO_BUY，再按商品ID排序。

四个原策略保持相同先验、问题、更新和终端推荐：

- **Fixed Order**：按冻结字段顺序提问。
- **Profile IG**：选择先验样本中回答熵最大的字段。
- **Decision-Set IG**：选择对可接受决策集合标签熵的预期减少最大的字段。
- **Decision Value（DV）**：选择观察该回答后，最优终端动作正确率的预期增量最大的字段；每次收到回答后重新选择下一问。它是一步决策价值目标，不声称多步最优规划或一般VOI原则为新发明。

关键消融 **Initial-order DV** 在空历史下计算六个原DV分数，一次排序后固定问题顺序。每个有效回答仍照常更新偏好和推荐；只移除在线选问重排。精确同分按原字段顺序处理。相同问题预算不代表相同计算量。

## 三种LLM顾客回答通道

Luna、DeepSeek V4.1 Flash、GLM-5.3均使用原开发面板48画像、35菜单、280案例。每画像的六个字段各调用一次独立会话，每模型288次原始请求；每个字段回答在该画像的不同菜单和策略间共享。提示给出既定偏好并要求仅返回所问字段的结构化JSON，不包含跨轮历史。本轮机制消融直接复用这些真实回答，没有新增模型调用。

推荐端一直为Python；LLM不选择最终商品，也没有验证自由表达、多轮偏好保持或真人购物行为。Luna是CLI请求别名，后台模型身份及采样参数未全部独立确认；DeepSeek和GLM为千问北京端点报告标识，不等于权重审计。DeepSeek/GLM显式temperature=1、top_p=1、high推理、8192输出上限；GLM使用完整SSE，仅最终content进入字段评分，reasoning不作为答案。Luna与另两部署的外层系统和解码不能完全对齐。

字段验证保持原严格JSON/类型/词表规则。有效但不忠实的回答按实际返回值使用，不用隐藏偏好修复。首次缺失、无效或观察异常后永久停问；失败问题仍计1单位，后续预算上限下继续用最后有效状态推荐。失败路径保留在全部280案例中，并按实际动作评分，不能统一记错或强制NO_BUY。

原DeepSeek先24次尝试保留10次TLS失败，后续只继续264个未尝试字段；GLM先6次保留5次传输失败，之后只继续282个未尝试字段并调整传输路径。这些是失败后的传输调整，原失败不重试、不补齐。Luna保留1条无效回答；GLM另有11条无效输出及1条有效但不忠实回答。对应原账目和收据见历史快照。

LLM消融重放5880条原DV记录，另生成5880条静态记录。预算0/1逐案一致；由于停问顺序不同，预算6不要求全体相同，也不要求100%正确。三模型共同完整有效的37画像/196案例仅作失败排除诊断；主结果始终使用每模型全部280案例。

## 估计量与区间

主估计量为画像–菜单案例均权的准确率差；画像均权作为敏感性分析。完整0–6曲线、失败、实际问题成本、硬约束、regret和胜/平/负均保留。

Python以split×pool×cohort分层（32层），重抽整个画像簇，所选画像的全部菜单共同携带。LLM按pool×cohort分层（12层），每次用相同画像抽样同时携带三个模型结果。因此三个部署不是840个独立顾客样本。画像簇数分别为288和48。

各采用10000次配对bootstrap和冻结种子，报告线性插值的点态百分位95%CI。Python同时带覆盖2个对比×7预算；LLM分别覆盖预算5的3模型主比较和3模型×7预算全曲线。两种权重分别构造区间，不能宣称它们拥有统一的全报告95%覆盖。

区间条件于固定菜单、固定先验和单次已实现回答库，只反映当前合成画像分布下的不确定性；不包含LLM重采样、人群、目录外商品或历史方法选择不确定性。本发布的便携入口从数值投影复算上述统计；原商品评分和模型原始回答验证仍依赖本地未公开输入。
