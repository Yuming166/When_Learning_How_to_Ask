# Myntra 受控闭环方法开发 v0.1

本实验把五项服饰属性、硬约束和“不买”选项接到一个有限问答闭环，比较固定顺序、
画像信息增益、推荐结果集合信息增益，以及直接优化预期推荐正确率的逐问策略。

模拟顾客是 Python `ReferenceUser`，每个字段都按构造画像精确回答；推荐策略是 Python
程序。**这里没有 Qwen/Luna 用户或 LLM 推荐 Agent，也没有自然语言可靠性或原来的
共享问法可靠性模型。**结果只用于闭环接口和有限画像开发诊断。

实验使用 Myntra v0.1 的12个构造画像、6个菜单、24个画像—菜单案例。策略的先验来自
独立种子生成的每品类2,048个构造画像；对照统一按六个等成本的字段问题计量。整画像
询问会额外报告为“1轮、6个信息单位”，不与一个字段问题等价。

复现入口和冻结要求见 [PROTOCOL.md](PROTOCOL.md)。本地原始目录、画像、先验样本和逐案
轨迹位于忽略跟踪的 `artifacts/`，不会进入 Git。来源目录路径可通过 `--source-worktree`
指定，必须保留原冻结目录和471件目录哈希。
