# Post-run parallel replay

All model calls completed before this offline analysis script was created. The pre-inference frozen runner remains unchanged and its hash manifest still verifies. To avoid a long single-process replay across 280 profile-menu cases, a post-run copy of the frozen runner was modified only to distribute independent case replays across the configured eight local worker processes. The same profile answers, deterministic `PublicPolicy`, query order/tie-breaking, evaluator, budgets, metrics, and deterministic-reference comparison are used. No model/API calls or prompt changes occur during analysis.

The first post-run summary attempt completed and persisted all 7,840 strategy-budget traces, then stopped at the bootstrap step because the new config did not duplicate the already frozen bootstrap settings. The corrected analyzer now reads the frozen full-development settings (10,000 repetitions, seed `202611041955`) and reuses the persisted trace rather than rerunning the 280 cases. This failure and correction occurred after collection; no output or call record was discarded.

Two post-run analyzer setup errors occurred before the final summary: the first summary pass did not load the frozen bootstrap settings; after that was corrected, a missing `pathlib.Path` import stopped the next invocation before completion. Both were fixed in the offline analyzer. The persisted traces were reused, and no model calls were repeated. The final post-run script is not claimed to have been pre-registered; its current SHA-256 is `803a7f082015961c240ed22552d8d743a259604e8ca68c87ead1ee702692264d`.
