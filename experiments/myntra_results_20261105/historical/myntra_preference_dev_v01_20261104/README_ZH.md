# Myntra偏好模拟器开发 v0.1

已完成数据适配、画像生成、购买评价器、公私信息隔离、问答接口、程序化推荐器
基线，以及16次真实本地Qwen回答测试。以471件目录为底座，仅从开发集抽取
48件商品；验证和测试预留集没有进入问答或效果评价。

先看[开发报告](REPORT_ZH.md)。关键结果：

- 12个构造画像、6个同类菜单、24个场景。18个应不买，其中13个仍有合格商品。
- Python与SQLite评价器一致；确定性参考用户的48条程序闭环均正确，仅用于验证接口。
- Qwen3.6-35B-A3B：16/16可解析；商品选择9/10符合固定规则；两条披露—推荐—
  最终决定的真实对话均符合规则。两位预定画像都应不买，没有购买正例覆盖。
- 保留两个错误：反转商品顺序后一次不该买却买；问法B一次额外声称接受干洗。
- 33项测试与2117项来源/记录/重放检查通过。没有训练或原方法与IG的比较。

请求计划；`evaluator_only/`为独立计算的参考结果。`artifacts/qwen_smoke/`保存
全部实际请求、响应、调用账本和逐条记录。不要把私有画像/参考结果交给策略。

这是一套“真实商家标签＋构造用户规则”的受控开发环境。积分与购买门槛是明确
加入的模拟假设，不能解释为重建了真人偏好或验证了自然共享可靠性。
