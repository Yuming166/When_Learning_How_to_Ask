## 风险回退、周期对照与条件限制

全部78路径/方法的决定日志、更新数和counter相互一致：Risk-Info回退329/3733=8.81%；Risk-Reuse323/3677=8.78%；Periodic907/3504=25.88%。纯参考的计算记在baseline/fallback计算分项，但条件回退次数为0，不能把0解释为没有计算。神经前向、风险、回退与包装余量均包含在相应完整路径计时；组件是嵌套诊断，不额外加回总CPU。

本轮没有证据支持风险启发式优于简单周期对照。不能由8.8%与25.9%的回退频率差异单独解释因果，更不能事后调阈值追平频率。

Periodic在按R聚合的主池相对Fused-Info均保留查询/CPU门通过；但这不等于每个OOD单元或变量维度都通过：

- rate-OOD、R16查询比1.06944，范围[1.02469,1.13043]，完整CPU1.945倍；rate-OOD、R64查询范围上界1.05042也略超5%。
- calibration-OOD、R16及R64查询范围上界分别1.08475及1.05357。每单元只有六世界，必须保留这些范围与完整分母。
- 变事实数六世界全部策略正确认证。Periodic相对Fused-Info查询比1.02308，范围[0.97546,1.07407]；完整CPU1.589倍，未满足查询范围和加速门。相对AnalyticReuse查询比1.05556，范围[0.98876,1.13636]，也未通过。

因此Periodic是一个有实用价值的开发候选，不能根据从多候选中选出的主池结果声称普遍或已独立确认。固定预算读数在原报告独立列出，均来自cap6144的同一置信轨迹，不是已知短截止时间的专用策略实验。

## 浮点参考与费用判断

Cold与AnalyticReuse在16/78个world/R的动作轨迹不同，其中三条在线数相差32，另外13条停止数相同。主池均值差1.333。应保留这项浮点/追踪差异，不能把T1a早期固定条件下的轨迹不变直接延伸为本轮所有新状态逐位相同。两者使用同一理论分配与独立严格停止门，不因局部数值等价而抹掉实际差异。

部署费用报告采用总获取、完整路径CPU及已有训练摊销，保留sunk、单次拟合和已知构造+拟合三种情景，给出不同M的参数化break-even。完整项目历史失败前缀费用未知，未来冷初始化和反馈价格未测，不能以零替代。Periodic相对Fused-Info平均多25.778个观测、节约0.783秒完整CPU；是否值得部署取决于反馈相对价格和训练摊销，不能只看2.145倍CPU。
