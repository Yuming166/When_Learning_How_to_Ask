# Learning How to Ask：Web 原生理论探索报告

日期：2026-10-31。结论：**采用 Option A，保留现有理论主线；完整 provenance-aware 重构为 REVISE。** 本轮得到了可写成命题的严格推导、精确反例和小规模解析计算，但没有确认足以独立支撑新论文的原创性，也没有验证真实 Web/LLM 生成过程。这里的 GO 是继续采用保守整合路线，不是论文已经可投或已被证明适合录用。

## 1. 最值得研究的问题

> Web agent 应该继续换一种方式读取已有网页，还是付费寻找一个真正独立的信息来源？

关键区别是：网页可能忠实地写着一个错误结论。更好的提问形式可以提高“读对网页”的概率，却不一定提高“网页说得对”的概率。同一上游报告的多个转载 URL 也不等于多份独立证据。

这个问题确实改变了原模型中的信息结构。它同时已有很近的文献祖先，不能仅靠术语和图模型宣称创新。

## 2. 现有理论：保留什么，哪里不能搬用

本轮核对了 `Theory_Note.md` 和用户提供的 expected-time 证明附件；附件绑定的原文件 SHA-256 与仓库一致。完整审查见 [EXISTING_THEORY_AUDIT.md](EXISTING_THEORY_AUDIT.md)。

保留的前提包括固定维度与已知分组、全局未知的 p/q、组内共享的未知 z、每次关于真值的新鲜条件独立回答、每条含 Mδ 个样本的两条有标签校准流，以及只有 z 信息的 oracle。原保证对离线样本随机性取平均。可选类型询问的准确率必须已知；未经验证的模型自我报告不满足这个前提。

原 Theorem 1 的联合 KL 规划、Theorem 2 的 oracle 分配、Theorem 3 的最小共享组条件继续作为原实验下的结果。本轮没有发现展开证明中的数学缺口：严格可行性给出最优集合稳定性，正在线信息裕量和可求和尾界支撑期望时间结论。结论仍针对理想估计、优化和似然计算，不自动覆盖实际程序的渐近最优性。

**不能直接搬用的部分：** 对一个持久、可能错误的网页反复抽取，不再产生关于事实真值的 iid Bernoulli 回答。原似然、停止界和 Γ 条件不能用“平均准确率替换”来修补。

## 3. 最小 Web 模型与识别性

模型链为 θ → V_i → Y_{i,m,t}：θ 是事实真值，V_i 是独立 provenance root i 一次生成后保持不变的报告，Y 是随机抽取结果。来源准确率 r 与抽取准确率 p/q 分开。页面到 root 的映射先设为已知；新 root 支付 c，每次抽取支付 ℓ。真实来源关系是否已知、独立性是否成立，需要另行实证。

先在单事实、已知同质 r 的模型中推导，再明确标注哪些命题还假设抽取率已知。没有将原来的“未知 p/q”悄悄改为已知后继续沿用原定理名称。

三种问题必须区分：

- 每个 root 只读一次时，只能看到有效准确率 ½+(2r−1)(a−½)，来源率与抽取率一般不能分别识别。
- 按模型对同一 root 重复抽取，可以识别抽取率与最佳格式。回答一致性在这里测的是抽取通道，不是事实真伪。
- 已知 r>½ 时，真值的两个分布通常不同，但有限根节点仍有正误差下限。这是有限证据饱和，不宜笼统叫作“参数不可识别”。

退化关系也明确：来源绝对正确时恢复原抽取模型；每次换独立同质来源时恢复有效 Bernoulli 通道，但离线校准必须匹配有效通道；若要进一步声称最优系数相同，还必须匹配有效参数的替代域，不能忽略已知来源率带来的域收缩。将目标改成恢复 V 则改变了科学问题；重复读取有限个不完美来源不能恢复原事实推断定理。

## 4. 推导结果与判断

完整命题、证明、极端情况及反例见 [WEB_THEORY_RESULTS.md](WEB_THEORY_RESULTS.md)。

| 方向 | 已经得到什么 | 本轮判断 |
|---|---|---|
| 有限来源信息饱和 | KL(H₊‖H₋) ≤ S·kl(r,1−r)；精确 Bayes/minimax 下限为二项多数表决错误率 | 作为适用边界 GO；独立创新 NO-GO，属于标准 DPI 推论，原笔记 §9 已有单源特例 |

| 抽取与验证分离 | 可以把 z,p,q 学得越来越准，同时事实错误仍不低于来源下限 | 可用作 Web 解释与实验设计；不能当成新的一般识别定理 |
| 受限批次最优性 | 每个新来源预定读取 k 次后丢弃时，最优系数为 minₖ(c+kℓ)/Dₖ | 推导成立；只覆盖该策略类，不能宣布完整 Agent 最优 |
| 状态与决策反例 | 相同事实后验、相同来源查询次数，可以要求不同的最优下一步 | 精确反例成立；说明方法必须保留来源层信息 |
| 昂贵来源下的格式溢价 | 已知 r,p,q、未知 z 时，先 δ→0 再 c→∞，未知格式/格式 oracle 的最优总成本比趋于 1，即使只有一个事实 | 最值得继续核查的结构性结果；原创性及未知参数扩展 REVISE |
| 完整共享格式＋自适应来源获取 | 尚无匹配的联合下界、可实现策略与新共享阈值 | REVISE，不替换目前的主理论 |

最后一个已证明的结构结果值得注意：原理论中，跨事实共享可以摊薄学习格式的成本；这里，即使没有共享，也可以因独立来源获取成本占主导，在指定的两阶段极限中使**相对**溢价趋于零。证明中的强基线只是每个来源对 A/B 各询问 k 次、把总计数送入序贯检验。它说明：在已知通道参数、来源成本占主导的这个极限中，达到一阶相对成本最优不必识别格式；当前证明没有划出任何有限成本区间。

它不意味着固定 c 的一阶系数相等，不意味着绝对成本差趋于零，也不是原未知 p/q 定理的推广。本轮尚未找到文献优先权的确定答案。

## 5. 两个具体例子与执行证据

**例一：多次提问不等于多份事实证据。** 设来源准确率 .8，抽取准确率 .9。同源 51 次回答后的最优 Bayes 错误约 .20；从 51 个独立来源各读取一次约 .00012。这个比较只固定抽取次数，不含来源获取成本，不能据此说独立来源策略总是更便宜。

**例二：只有事实置信度不够。** 设来源准确率 .8，抽取准确率 .7，抽取的损失成本 .01，新来源的额外损失成本 .02。两组历史都让 P(θ=+)=.5，每个旧来源都已读两次：

| 历史 | 旧来源 1 | 旧来源 2 | 继续读取的总损失 | 获取新来源的总损失 | 停止损失 | 最优动作类别 |
|---|---|---|---:|---:|---:|---|
| H1 | +,− | +,− | .39 | .41 | .50 | 继续读取 |
| H2 | +,+ | −,− | .4340746 | .41 | .50 | 获取新来源 |

这些值来自分数运算的精确枚举，不是 Monte Carlo 拟合。完整的有限预算 Bellman 计算还比较了 12 个预算/成本设置，保留全部结果。在 r=.8、a=.7、c=1、预算 9 时，最优 Bayes 错误为 .27299048，始终换新来源为 .323456，始终读一个来源为 .2756216。这只说明一个小型解析实例中的差别。

受限批次问题中，当 ℓ=1、r=.8、a=.7，c 从 0、1、3、10 增加到 50，数值求得的最佳读取深度依次为 1、3、5、9、18。新来源越贵，同源深读越值得；总体成本也随之改变，不能把读取深度增加解释成普遍更高效。

本轮执行：162 个一步公式核对、8 个精确来源误差下限核对、12 个有限预算比较；KL 示例采用 80 位 Decimal 数值，未声称区间认证。**0 次 Qwen 推理、0 次训练、0 个采样实验世界。** 同模型家族的分工审查不是跨家族验证或形式化证明。

## 6. 新颖性审计：不能再作为新意的部分

[WEB_THEORY_NOVELTY_MAP.md](WEB_THEORY_NOVELTY_MAP.md) 逐篇记录了 12 篇近邻的模型、假设、结果、实际阅读范围、重叠和缺失证明。最强的否定性证据是：

- [Dong 等，2009](https://www.vldb.org/pvldb/vol2/vldb09-pvldb47.pdf) 已处理复制来源依赖。
- [Knowledge-Based Trust，2015](https://www.vldb.org/pvldb/vol8/p938-dong.pdf) 已区分来源事实错误与抽取错误，还共享网站/抽取模式层级的可靠性。
- [Less is More，2012](https://www.vldb.org/pvldb/vol6/p37-dong.pdf) 已研究有成本的来源选择。
- [受控 Markov 检验](https://arxiv.org/abs/1310.1844) 已有非均匀成本下的 KL 率最优性；其有限已观测状态条件不能直接覆盖不断增长的隐含来源状态。
- [Sequential Testing with Subadditive Costs，2025](https://arxiv.org/abs/2501.18010) 已包含激活成本，但目标是组件测试，不是有抽取误差的事实认证。

所以“two-layer noise”“provenance-aware”“cost-aware”“group-shared”这些词本身都不足以构成贡献。若推进 B，必须把新贡献落在它们相互作用后的可证明成本边界，而不是宣称这些部件首次结合就有原创性。

## 7. 最小后续实验：先验证哪一种误差存在

后续实验应先冻结以下三种机制，再在相同潜在真值和成本口径下比较。以下是建议，**本轮未启动**：

1. 原始 iid 真值回答，作为理论恢复对照。
2. 少量持久来源报告＋新鲜抽取噪声，检验误差是否在预测下限饱和。
3. 同一模型允许付费激活独立新来源，比较预算分配及来源数量。

基线至少包括固定格式、A/B 轮询、固定深度来源块、始终换新来源、只读已有来源，以及小规模精确 Bellman 参考。已知 z 的 oracle 只额外知道 z；若报告完全可见，要单独叫 report oracle。保持来源准确率、p/q、目标和访问成本口径一致。

先报告来源数、每源抽取深度、总访问成本、对 V 的抽取准确率、对 θ 的事实准确率与错误认证率；不能只报一个 Accuracy。直接类型询问与公开元数据仍应保留，不能把可轻易识别 z 的场景包装成学习优势。

若要连接真实 Web，只需先做很小的人工核验材料：明确上游 provenance、页面实际声明 V、独立事实标签 θ；把同源复制与独立起源分开。不同 URL 或域名不能直接作为独立性标签。重复回答稳定但共同读错的现象应单列为持久抽取错误，不能被模型归入来源错误。只完成这种材料核验也不能证明条件 iid。现有 CRAG/Natural 工作不在本轮证据中。

未知格式的完整理论优先解决一个事实、已知来源率、已知 p/q、允许 revisit 的固定成本问题；再逐层加入共享、未知水平和有限校准。不要一次引入未知来源图、漂移和策略性错误。

当前可写的主张是：原模型解释共享接口可靠性如何影响询问信息成本；Web provenance 指出这种收益的明确边界——更准确地读取已有声明不等于获得更多独立事实证据。应把饱和命题放在适用范围/边界中，不能宣称它补完了真实 Web 的最优查询算法。

若随后希望采用 B，本轮 Proposition 5 是一个值得继续审查的候选结构结果；需要进一步排查最近邻、解释成本尺度的实际意义，并决定是否能处理未知水平。没有这些证据前，保持现有 Theory + Method 稿件作为主线。
