# 混合深度优势：从孤立实例到显式参数区域

日期：2026-11-01。结论：**本轮理论补强完成。** 在原模型中，混合深度的严格优势在一个五维参数盒内持续成立；校准量与访问成本都有明确区间。

## 可直接使用的结果

设每次读取成本为 ell，访问新来源的成本为 c。每个来源保留同一份可能错误的报告；对它重复读取只能降低提取不确定性，不能获得新的独立来源。令

\[
\alpha=\lim_{\delta\to0}\frac{M_\delta}{\log(1/\delta)},
\]

其中 M_delta 是**每条**高/低可靠性标定流的样本数，总标定样本为 2M_delta。

| 参数 | 经过证明的区间 |
|---|---|
| 来源正确率 r | [0.599975, 0.600025] |
| 优势形式提取正确率 p | [0.949975, 0.950025] |
| 另一形式提取正确率 q | [0.599975, 0.600025] |
| 标定量系数 alpha | **[0.95, 1.20]** |
| 访问成本 / 单次读取成本 c/ell | **[0.5, 1.5]** |

固定 d=1、最大深度 6、eta=1/40，保留所有 27 种读取块。Oracle 只知道哪种形式更好，仍不知道 p、q 和真值。r 在每个实例内仍然是已知量。

记 K_or 为允许混合深度的最优渐近在线成本系数，K_L 为固定深度 L 的最优系数。固定深度基线仍可使用该深度下全部形式组合。整个参数盒内有

\[
K_{\rm or}\le16c+18\ell,
\qquad
\min_{1\le L\le6}K_L\ge16c+18\ell+\frac{15}{7}\ell.
\]

因此，**每个最优分配都必须包含至少两个不同深度**。相对任何固定深度，最优在线成本系数至少降低

\[
\boxed{\frac5{103}\approx4.85\%.}
\]

若固定 r=q=0.6、p=0.95，同样的 alpha 和成本区间内可提高为：统一加性差至少 9ell/4、相对降低至少 3/59，约 5.08%。原中心实例的较大优势仍保留在旧证书中；这些新百分比是整个区域统一成立的保守下界。

## 证明怎样完成

1. 沿用纯优势形式的两深度可行分配 x_1=14、x_2=2，成本为 16c+18ell。
2. 重新计算整个连续备择参数域，证明中心实例的信息约束余量严格超过 1/35。950 个区间各自使用精确对数区间和二阶余项，覆盖连续域。
3. 凸性给出标定 KL 的全局上界 103/200。将 alpha 降到 0.95 后仍有 79/28000 的余量。
4. 推导该信息函数对 r、p、q 的总导数绝对值小于 100。三个参数分别移动至多 1/40000 后，仍有 **9/28000** 的统一信息余量。
5. 对固定深度分别构造对偶下界，并对全部 27 种形式组成验证扰动后的严格不等式。连续成本区间通过仿射函数的端点不等式覆盖。

这给出了全维开邻域的具体内盒，避免只诉诸“连续性意味着附近也成立”。可靠性参数区间很窄，是为了给出容易复核的显式证书；没有证明它是最大区间。

## 对论文的作用

现在可以将原来的“某个参数点存在混合深度反例”加强为：

> 有限标定下，在一个具有非空内部的参数区域内，来源访问与重复提取之间存在严格的深度分配权衡；任何固定深度都与最优值存在统一正间隔。

这个结论与 Web 的来源访问成本、持久来源错误和重复提取机制直接相连。它补齐了现有反例是否依赖精细调参的问题。适合把区域定理作为正文结论，精确算术与扰动细节放入随附证明和复现材料；若投稿页数限制包含附录，正文必须明确标注其计算机辅助性质，不能假定附录不计页数。

仍不能据此声称：所有参数下纯优势形式都最优；最优解恰好只需要两个深度；有限预算时必然降低 4.85%；真实 Web/LLM 已满足模型；或这是最大相变边界。两条标定流若另行收费，加性在线成本差仍然成立，上述总成本百分比不能直接沿用。
