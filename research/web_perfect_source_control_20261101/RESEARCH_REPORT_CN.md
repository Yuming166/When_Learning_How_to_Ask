# 机制对照完成：来源完全正确时，不再需要混合深度

日期：2026-11-01。**本轮已完成第一项工作，得到解析定理及匹配的渐近期望成本结论。** 不仅证明了最大深度足够，还精确刻画了所有固定深度的最优成本，并恢复了原理论的最小共享组判据。

## 1. 新定理

把来源正确率扩展到已知边界 r=1，其他条件不变：p、q 仍未知，仍有有限校准、未知组内最佳形式、正的单次读取成本，以及最大读取深度 N。结论适用于任意固定事实数和已知分组；没有直接类型询问。

记 T 为原始独立回答模型的最优在线读数系数，K 为这里的最优在线成本系数。则对学习者和只知道最佳形式的 oracle，分别都有

\[
\boxed{K=\left(\ell+\frac cN\right)T.}
\]

这里 c 是每个新来源的访问成本，ell 是一次读取的成本。任意固定深度 L 的最优系数恰为

\[
K_L=\left(\ell+\frac cL\right)T,
\qquad K_L-K_N=c\left(\frac1L-\frac1N\right)T.
\]

因此：

- **c>0：每个最优信息分配都只使用最大深度 N。** 短深度不能获得一阶正权重。
- c=0：每个固定深度都能实现相同最优值，混合深度仍非必要。
- 总能仅用纯格式的最大深度块达到最优；这不等于学习者的所有最优解都必须纯格式。
- Oracle 在 c>0 时具有唯一的纯优势形式最大深度分配。

## 2. 证明为什么成立

来源报告完全正确时，同一来源内的随机性只来自独立抽取。对一个含 a 次 A 和 b 次 B 的块，完整计数分布的 KL 严格等于

\[
D_{a,b}=aD_A+bD_B.
\]

这个等式同时适用于全部错误真值、类型交换和连续可靠率备择。于是可以把任意分配里的 A、B 总读取数分别重新组合为深度 N 的纯格式块：所有信息约束保持不变，只减少了访问次数。

若 x 是原块分配，S 是总读数系数，成本有精确分解

\[
C(x)=\left(\ell+\frac cN\right)S
+c\sum_{j,a,b}\left(1-\frac{a+b}{N}\right)x_{j,a,b}.
\]

最后一项就是使用不足最大深度的块所支付的额外访问成本。c>0 时，只要有正权重短块，该项就严格为正。

原来的 r<1 期望成本证明用到了 kl(r,1-r)，不能直接代入 r=1。本轮单独修补了这一点，利用逐读取 KL 可加性建立正在线信息下界，再在只含最大深度块的菜单中构造探索、跟踪与有效停止策略。因而结论不止停留在信息规划上，也有匹配的渐近期望在线成本解释。

## 3. 对原共享理论的直接连接

学习者和 oracle 的成本都乘以同一个正数，因此

\[
K_{\rm learner}=K_{\rm oracle}
\iff\Gamma_{k_{\min}}(\alpha)\ge1.
\]

**来源完全正确时，访问成本和共同深度上限只改变成本尺度，不会改变零一阶形式溢价的共享门槛，也不会改变相对形式溢价。** 绝对溢价随尺度改变。这是原始共享理论与 Web 扩展之间一个明确、精确的恢复关系。

## 4. 现在形成的三种机制对照

固定 p=.95、q=.6、单事实、最大深度 6、访问与读取成本均为 1。比较对象统一为“知道最佳形式”的 oracle。

| 对照 | 最优深度结构 | 证据状态 |
|---|---|---|
| 来源完全正确；p、q 未知，alpha=1 | 唯一选择深度 6 | 本轮解析定理 |
| 来源正确率 .6；额外揭示 p、q | 唯一选择深度 1 | 旧精确证书 |
| 来源正确率 .6；p、q 未知，alpha=1 | 每个最优分配都必须混合至少两个深度 | 旧连续域证书，并已扩展到非退化参数区域 |

已知可靠率的一般情形可能有并列最优深度，因此一般结论是“存在单深度最优解”；中心实例才具有深度 1 的唯一性。

这组对照支持论文中的机制陈述：**持久来源错误与未知抽取可靠率共同存在时，有限校准下可能出现严格必要的深度混合；分别移除来源错误或揭示抽取可靠率，都能消除这种强制混合的现象。** 不表示所有含这两个因素的实例都必须混合。

## 5. 保留的边界

这是规定模型中的机制分离，不是对真实网页进行的因果实验。r=1 必须是所有备择模型共同知道的条件；只让真实来源恰好正确、却仍允许未知来源质量的备择，不满足定理。

最大深度上限、完成块后放弃来源、没有块内决策与重访等限制保持不变。这里的最大深度结论不能直接推广到不受这些约束的浏览 Agent。

理论针对渐近成本系数。有限预算时，批次边界会影响适应与停止，不能声称把任意逐次自适应策略打包后具有完全相同的有限样本表现。另一个渐近最优策略也可以包含低阶数量的短块。
