## 1. 目前究竟已经有什么

我们已有一套从“学习怎样问”走向“学习怎样获取证据”的理论链条。

| 层次 | 已有核心结论 | 对论文的用途 |
|---|---|---|
| 学习问法的代价 | 联合未知 p,q 的最优信息成本；最小共享组决定零一阶形式溢价 | 原研究的结构主线，理论完整度较高 |

| 成本怎样改变学习 | 已知率下，来源访问费通过最优深度改变共享需求 | 将来源获取成本和问法可靠性连接起来 |

## 2. 最适合 Web 的 motivation

设一个检索增强系统正在核验一个带有主体、时间和版本限定的 Web 命题。它已经找到一份报告，还可以换一种读取形式、再次读取、打开转载，或者寻找新的独立来源。需要决定的是：付费获取哪一种观测，才能以目标错误率恢复事实。

这个任务同时存在两层错误。页面可能准确表达了一项错误报告；读取器也可能把页面陈述理解错误。提高读取准确率能够帮助确定页面说了什么，却不能保证页面所说为真。同一报告的转载还会重复前一层错误。[来源依赖](https://www.vldb.org/pvldb/vol2/vldb09-pvldb47.pdf)与[来源/抽取分层](https://www.vldb.org/pvldb/vol8/p938-dong.pdf)均已有研究，本工作应明确承接这些基础。

预算分配因而涉及两种不同价值：对同一来源增加读取，可以减少对其陈述和读取通道的不确定性；获取独立来源，可以增加新的报告证据。两种操作都可能提供多方面信息，不能简单分成“深读只学可靠性、浅读只学真值”。来源访问成本、未知读取可靠率和有限参考数据共同决定哪一种信息更值得购买。

**我们的候选核心发现是：即使最佳读取形式已经告诉系统，只是不知道它究竟有多可靠，最优一阶分配也可能必须使用不同来源读取深度。** 这说明“先找到最佳问法，再给每个来源固定读取次数”的化简可能丢失最优性。

本句限定在规定的完成块策略类；“不同深度”指跨来源块分配不同读取次数，不等于已经证明一个可自由重访、逐步浏览的实际 Agent 必须如何行动。

混合深度也不等于观测自适应：事先安排不同深度的来源块同样属于混合设计。主定理排除的是统一固定深度，没有排除全部预先安排的混合方案。超过全部静态分配的观测自适应优势由W2a另行研究，不能从这里直接推出。

## 3. 一条可写成引言的故事

**第一步：提出 Web 决策。** 检索和抽取需要共同使用预算。问题是带成本的可靠证据获取，而非仅对已经收集的所有文本做最终投票。

**第二步：明确证据单位。** 真值 θ、来源报告 V 和读取输出 Y 是三件事。重复读 V 与获得新的独立 V 不同。provenance 在此用于声明证据来源归属；不声称自动发现未知来源图。

**第三步：从已知可靠率走到有限校准。** 已知率时，在完成块模型内存在一个固定深度最优解。真实应用中可靠率需估计，因此我们研究有两路有标签、有限规模参考数据的严格模型，而不把估计值当作真值代回原检验。

**第四步：给出结构分离。** 一个一事实例子已经排除所有固定深度，连同每个深度下的全部格式组合。分离不只在一个点成立：校准量和访问成本有明确区间，可靠率也有经证明的非空内盒。

**第五步：解释来源错误与未知率的交互。** 来源已知完全正确时，访问费使最大深度最优；同样不完美的来源但额外揭示抽取率时，存在单深度最优；两种不确定性同时保留且校准有限时，出现强制深度混合。

**第六步：回到原理论与范围。** 完美来源边界精确恢复原始共享模型，因此它们是相连的理论，而不是两段不相干的推导。一般多读下的最小组标量门槛仍开放，本文不以解完这一问题作为贡献。

一句话中文故事：

> 有限校准下，Web 证据获取不仅要决定信任哪一种读取形式，还要决定每个独立来源读多少次；持久来源错误与未知读取可靠率共同存在时，任何统一固定深度都可能付出严格的一阶成本代价。

英文主张草案：

> In a completed-source-block model, persistent source errors and finitely calibrated extraction reliability can make every fixed reading depth strictly suboptimal, even when the better extraction format is known.

它是模型内的定理主张，不是现实 Web 的普遍规律。

## 4. Web 关联的强弱

| Web 对象 | 在数学中真正改变什么 | 证据边界 |
|---|---|---|
| 持久的来源陈述 | 同根回答相关，关于真值的信息饱和 | 来源报告及读取独立性由模型规定 |
| 转载和归因 | 多个页面可共享一个 V；URL 数不等于证据根数 | 主定理假设来源归属已知，不处理任意未知复制图 |
| 来源获取和读取成本 | 一个新根支付 c，每次抽取支付 ℓ；不同深度有不同信息/费用 | 成本是受控定义，尚未测得实际 Web 延时/费用 |
| 有限历史校准 | p,q 仍是检验中的连续 nuisance 参数 | 高/低流身份已知是较强信息假设，不能用普通聊天记录冒充 |
| 可迁移的问法可靠性 | 原理论中多个事实共享 z_g | 假设共享；目前未建立自然 Web 的稳定共享规律 |

这些机制也存在于其他应用。论文无需宣称它们为 Web 独有，但第一页必须具体说明 Web 证据获取的问题、决策与适用子域。官网明确要求第一页给出 Web/track 关联；仅使用 Web 数据或 API 不足。[官方征稿](https://www2027.thewebconf.org/research-track-papers/)

W1 的12条声明、50个URL审计保留了2条候选、10条隔离，并未得到可测量的自然错误来源正文或模型读取数据。它说明把整页强制转成二元报告有适配困难；不能用作本理论的经验验证。W1.1 的语义修复也未建立最终人工签核。无需为了这篇受控理论论文继续人工标注，但必须保持这一主张边界。

## 5. 三种可能的论文，选择哪一种

| 故事 | 最强结果 | 主要风险 | 本轮建议 |
|---|---|---|---|
| S：共享问法何时免费 | 最小共享组充要条件、有限校准与精确 oracle | 自然共享未建立；Web 需要具体交互问题与证据支持 | 保留为原 Method/理论稿路线，不宣称被新结果替代 |
| D：固定来源读取深度何时失效 | 强制混合区域＋两种机制对照＋完美来源恢复 | 单事实受限模型、计算辅助证明、窄可靠率盒；新颖性尚需最终判断 | **推荐当前 Web 理论短文候选** |
| A：自适应何时胜静态 | W2a 有限预算、超过全部静态分配的稳定分离 | 已知通道；通用自适应设计先例多；合成语料无实际读取 | 配角或另一独立小结果，四页不足时删去 |

不建议用“统一框架同时解决共享、来源图发现、真实模型训练、最优浏览与认证”作为标题或摘要。现有证明没有覆盖如此大的范围。

推荐工作标题：

**When Fixed Reading Depth Fails: Web Evidence Acquisition with Finite Calibration**

标题不承诺未知 provenance 学习或完整 Web Agent。它直接指向可被证明、也可被证伪的结构结论。
